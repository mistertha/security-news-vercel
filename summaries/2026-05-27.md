## Critical

### 🚨 KnowledgeDeliver zero-day ถูกใช้ติดตั้ง web shell
- สรุป: BleepingComputer รายงานว่าช่องโหว่ `CVE-2026-5426` ในระบบ LMS ชื่อ KnowledgeDeliver ถูกใช้เป็น zero-day เพื่อโจมตีแบบ ViewState deserialization โดยไม่ต้องยืนยันตัวตน และนำไปสู่การรันโค้ดระดับระบบปฏิบัติการบนเซิร์ฟเวอร์ ASP.NET จากนั้นผู้โจมตีวาง Godzilla web shell และหลอกผู้ใช้ให้ดาวน์โหลดตัวติดตั้งปลอมเพื่อลง Cobalt Strike เพิ่มเติม เหตุการณ์นี้กระทบงานดูแลเว็บแอปและเซิร์ฟเวอร์ Windows/IIS โดยตรง
- CVE: `CVE-2026-5426`
- ประเภทการโจมตี: Unauthenticated RCE, ViewState deserialization, web shell deployment
- คำแนะนำ: อัปเดตหรือทำ hardening ตามคำแนะนำผู้ผลิตทันที, เปลี่ยน machine key ที่ใช้ร่วมกัน, ตรวจสอบไฟล์ `web.config` และ JavaScript ที่ถูกแก้ไข, สแกนหา Godzilla/Cobalt Strike และย้อนดู log การเรียก ViewState ที่ผิดปกติ
- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/knowledgedeliver-flaw-exploited-as-a-zero-day-to-install-web-shells/)

### 🚨 CISA สั่งเร่งปิด Drupal SQL injection ที่ถูกโจมตีแล้ว
- สรุป: BleepingComputer รายงานว่า CISA สั่งให้หน่วยงานรัฐบาลสหรัฐเร่งแก้ `CVE-2026-9082` ใน Drupal หลังพบการโจมตีจริงแล้ว ช่องโหว่นี้อยู่ใน database abstraction API และเปิดทางให้ SQL injection บนระบบที่ใช้ PostgreSQL โดยข่าวต้นทางระบุความเสี่ยงต่อการยกระดับผลกระทบไปถึงการรันโค้ดหรือการเปิดเผยข้อมูลได้ หากยังมี Drupal ฝั่ง production ที่เปิดอินเทอร์เน็ตอยู่ถือว่าเร่งด่วนมาก
- CVE: `CVE-2026-9082`
- ประเภทการโจมตี: SQL injection, possible RCE, active exploitation
- คำแนะนำ: อัปเกรด Drupal ไปยังรุ่นที่แก้แล้วทันที, ตรวจสอบว่า instance ใดใช้ PostgreSQL, ทบทวน WAF และ database log หาคำสั่งผิดปกติ, และสำรวจ web root/บัญชีแอปสำหรับร่องรอย post-exploitation
- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-actively-exploited-drupal-vulnerability/)

## High

### 🔥 Microsoft แก้ SharePoint RCE ข้ามหลายรุ่นเซิร์ฟเวอร์
- สรุป: The Hacker News รายงานว่า Microsoft ออกแพตช์สำหรับ `CVE-2026-45659` ซึ่งเป็นช่องโหว่ deserialization of untrusted data ใน SharePoint Server ที่ทำให้ผู้โจมตีที่มีสิทธิ์ต่ำระดับ Site Member สามารถรันโค้ดผ่านเครือข่ายได้ แม้ยังไม่เห็นหลักฐานว่าถูกใช้จริงในข่าวนี้ แต่ SharePoint เป็นระบบที่เคยถูกโจมตีซ้ำหลายรอบและมักมีข้อมูลสำคัญอยู่ภายในองค์กร
- CVE: `CVE-2026-45659`
- ประเภทการโจมตี: Authenticated RCE, deserialization
- คำแนะนำ: ติดตั้งแพตช์ให้ SharePoint Server Subscription Edition, 2019 และ 2016 โดยด่วน, จำกัดสิทธิ์บัญชี Site Member ที่ไม่จำเป็น, ตรวจสอบ log การอัปโหลด/เรียกใช้ payload ผิดปกติ และเฝ้าดูการเคลื่อนย้ายด้านข้างจากเซิร์ฟเวอร์ SharePoint
- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/05/microsoft-patches-sharepoint-rce-flaw.html)

### 🔥 MuddyWater ใช้ DLL side-loading และ Node.js ในแคมเปญสอดแนม
- สรุป: The Hacker News ระบุว่ากลุ่ม MuddyWater ใช้ DLL side-loading ผ่านไฟล์ที่มีลายเซ็นถูกต้อง ร่วมกับ `node.exe` และ PowerShell เพื่อทำ reconnaissance, ขโมยข้อมูลจาก Chromium-based browsers และสร้างช่องทางสื่อสารย้อนกลับในหลายประเทศ ข่าวนี้ไม่ผูกกับ CVE โดยตรงและยังไม่ชัดเจนเรื่อง initial access แต่รูปแบบการโจมตีชี้ว่าฝั่ง Windows workstation และ server ที่อนุญาตการรันสคริปต์หรือ binary ที่เชื่อถือได้อาจถูกใช้เป็นฐานสอดแนมได้
- CVE: ไม่พบในแหล่งข่าว
- ประเภทการโจมตี: DLL side-loading, cyber espionage, credential theft, PowerShell/Node.js post-exploitation
- คำแนะนำ: ตรวจสอบการรัน `node.exe`, PowerShell และ DLL ที่โหลดคู่กับ binary ปกติแบบผิดที่ผิดทาง, บล็อก outbound ไปยังบริการแชร์ไฟล์สาธารณะถ้าไม่จำเป็น, ทบทวน EDR detection สำหรับ side-loading และเก็บหลักฐาน browser credential access บนเครื่องเป้าหมาย
- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/05/muddywater-uses-dll-side-loading-in.html)
