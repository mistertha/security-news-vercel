### 🔴 Glassworm botnet disrupted after resilient C2 infrastructure takedown
- สรุป: CrowdStrike, Google และ Shadowserver ร่วมกันตัดช่องทางสั่งการของ GlassWorm ได้พร้อมกันทั้ง 4 แบบ แต่ความเสี่ยงยังสูงเพราะแคมเปญนี้เคยใช้ส่วนขยาย VS Code/OpenVSX และแพ็กเกจ npm เพื่อขโมย token นักพัฒนา, ข้อมูลเบราว์เซอร์ และใช้เครื่องที่ติดเชื้อเป็นจุดกระโดดต่อไปในซัพพลายเชนได้ แหล่งข่าวระบุว่าเคยมีผลกระทบต่อ GitHub repository มากกว่า 300 แห่ง และ artifact มากกว่า 400 รายการ
- CVE: ไม่พบ
- รูปแบบการโจมตี: Supply chain attack, credential theft, RAT/C2 infrastructure
- คำแนะนำ: ตรวจหา IOC การติดต่อไปยัง `164.92.88[.]210`, ใช้กฎ YARA ที่ผู้วิจัยเผยแพร่เพื่อตรวจหาเครื่องติดเชื้อ, หมุน GitHub/npm/OpenVSX token และทบทวน extension หรือ package ที่ติดตั้งในเครื่องนักพัฒนา
- แหล่งข่าว: https://www.bleepingcomputer.com/news/security/glassworm-botnet-disrupted-after-resilient-c2-infrastructure-takedown/

### 🔴 Malicious npm Package Stole Files From Claude AI User Directory via GitHub
- สรุป: พบแพ็กเกจ npm ชื่อ `mouse5212-super-formatter` ทำงานแบบ postinstall เพื่อยืนยันตัวตนกับ GitHub แล้วสร้างหรือใช้ repository ของผู้โจมตีสำหรับอัปโหลดไฟล์จาก `/mnt/user-data` ออกไป ข้อมูลในข่าวบอกว่าแพ็กเกจยังถูกดาวน์โหลดได้ในช่วงที่รายงาน และมีความเสี่ยงต่อเครื่องนักพัฒนาที่เก็บ source code, secret หรือไฟล์งานไว้ในโฟลเดอร์ดังกล่าว
- CVE: ไม่พบ
- รูปแบบการโจมตี: Malicious npm package, postinstall abuse, data exfiltration

### 🔴 AI Chatbot Recommendations Redirect Users to Cryptojacking Malware Sites
- สรุป: Microsoft เตือนถึงแคมเปญที่ใช้คำตอบจาก AI chatbot เป็นทางพาผู้ใช้ Windows ไปยังเว็บดาวน์โหลดปลอมของเครื่องมือยอดนิยม ก่อนใช้ DLL sideloading, ติดตั้ง ScreenConnect, ตั้ง scheduled task และเพิ่ม Defender exclusions เพื่อคงอยู่ในระบบ จากนั้นจึงดาวน์โหลดตัวขุดคริปโตและเปิดทางสำหรับการขโมยข้อมูลหรือเคลื่อนที่ด้านข้างภายหลัง
- CVE: ไม่พบ
- รูปแบบการโจมตี: LLM/SEO poisoning, DLL sideloading, cryptojacking, remote access persistence
- คำแนะนำ: บังคับให้ดาวน์โหลดซอฟต์แวร์จาก vendor ที่เชื่อถือได้เท่านั้น, เฝ้าระวัง ScreenConnect, `msiexec.exe`, การแก้ไข Defender exclusions และ scheduled tasks ผิดปกติ, พร้อมบล็อกโดเมนหรือ IOC ที่เชื่อมโยงกับแคมเปญนี้
- แหล่งข่าว: https://thehackernews.com/2026/05/ai-chatbot-recommendations-redirect.html
