## High

### 🔴 High — IronWorm โจมตี supply chain บน npm ขโมย credential และแพร่ต่อด้วยบัญชีที่ถูกยึด

- สรุป: BleepingComputer รายงานว่าแคมเปญ IronWorm ทำให้ 36 แพ็กเกจบน npm ติดมัลแวร์ infostealer ที่เขียนด้วย Rust, ใช้ eBPF kernel rootkit เพื่อซ่อนตัว และมุ่งขโมย environment variables กับไฟล์ credential ที่อาจมี OpenAI, AWS, Anthropic, npm, Vault, SSH key และข้อมูล wallet หลังยึด developer หรือ CI environment ได้ มัลแวร์สามารถใช้ credential ที่ขโมยมาเผยแพร่แพ็กเกจเวอร์ชัน trojanized ต่อไปได้ รวมถึง secret ที่เกี่ยวกับ npm Trusted Publishing แม้รายงานระบุว่าถูกตรวจพบเร็วและหยุดก่อนลามไปยังแพ็กเกจยอดนิยม แต่ความเสี่ยงต่อ CI/CD และบัญชีผู้ดูแลแพ็กเกจยังสูง
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: npm supply-chain worm, credential theft, CI/CD artifact abuse, Rust malware และ Linux eBPF rootkit
- การดำเนินการที่แนะนำ: ตรวจ dependency tree และ lockfile สำหรับแพ็กเกจ/เวอร์ชันที่ได้รับผลกระทบตามรายงาน JFrog/OX Security, อัปเกรดเป็นเวอร์ชันที่แก้แล้ว, rotate npm token, cloud key, SSH key และ CI secret ที่อยู่ในเครื่องหรือ workflow ที่ติดตั้งแพ็กเกจดังกล่าว, บังคับใช้ 2FA/passkey สำหรับบัญชี npm/GitHub และเพิ่ม alert สำหรับ preinstall script หรือ GitHub Actions artifact ที่บรรจุ secret
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-ironworm-malware-hits-36-packages-in-npm-supply-chain-attack/)

## Medium

### 🟡 Medium — Hola Browser for Windows ถูก compromise เพื่อส่ง Monero cryptominer

- สรุป: BleepingComputer รายงานว่าเวอร์ชัน Windows ของ Hola Browser ถูก compromise ในลักษณะ supply-chain และติดตั้ง executable ที่ไม่ได้ประกาศชื่อ `me.exe` ใต้ `C:\Program Files\Hola\` ไฟล์นี้ไม่มีลายเซ็นดิจิทัล มีโค้ด obfuscation และ Sophos พบสัญญาณว่าเป็น Monero miner มัลแวร์เพิ่ม Windows Defender exclusion, คัดลอกตัวเองเป็น `HolaMonitorService.exe`, สร้าง service ชื่อ `hola_monitor_svc` และทำงานตอนเครื่อง idle ผู้ผลิตระบุว่ากระทบประมาณ 0.1% ของผู้ใช้และยังไม่พบหลักฐานการเข้าถึงหรือขโมยข้อมูลผู้ใช้
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: Windows software supply-chain compromise, cryptomining malware, persistence ผ่าน Windows service และ Defender exclusion
- การดำเนินการที่แนะนำ: ตรวจเครื่อง Windows ที่ติดตั้ง Hola Browser หา `me.exe`, `HolaMonitorService.exe`, service `hola_monitor_svc` และ Defender exclusion ที่ผิดปกติ, ถอนหรือติดตั้งใหม่จากแหล่งที่ยืนยันแล้ว, บล็อก hash/IOC จากรายงาน Sophos เมื่อมีในระบบป้องกัน, ตรวจ CPU/idle-time mining behavior และพิจารณาจำกัดการใช้ browser/VPN ที่ไม่จำเป็นในองค์กร
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hola-browser-for-windows-compromised-to-deliver-cryptominer/)

### 🟡 Medium — TA4922 ขยาย phishing เพื่อส่ง Atlas RAT, RomulusLoader และ SilentRunLoader

- สรุป: The Hacker News รายงานว่ากลุ่ม TA4922 ซึ่งเป็น threat actor ภาษาจีนและมีแรงจูงใจทางการเงิน ขยายการโจมตีไปยังองค์กรใน U.K., Germany, Italy และ South Africa โดยใช้ phishing lure แนว HR, tax, invoice, benefits และ compliance เพื่อส่งมัลแวร์บน Windows เช่น Atlas RAT ผ่าน DLL side-loading, RomulusLoader และ SilentRunLoader บางแคมเปญพยายามย้ายบทสนทนาไปยัง LINE, WhatsApp หรือ Microsoft Teams เพื่อเลี่ยงการควบคุมอีเมลและเพิ่มโอกาสส่ง malware หรือขโมยข้อมูล Chrome
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: phishing, Windows RAT, DLL side-loading, loader malware, credential/browser-data theft และ out-of-band social engineering
- การดำเนินการที่แนะนำ: เพิ่ม detection สำหรับ DLL side-loading และการ spawn เครื่องมือ remote access เช่น AnyDesk/SyncFuture จากเอกสารแนบหรือ loader, เฝ้าระวังอีเมล HR/tax/invoice ที่ชวนย้ายไปแชตภายนอก, จำกัดการรัน executable จากพื้นที่ user-writeable, ตรวจพฤติกรรมดึงข้อมูล Chrome และอัปเดต rule/IOC จาก Proofpoint เมื่อเผยแพร่
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/china-linked-ta4922-expands-phishing.html)
