## High

### 🔴 High — CISA ระบุ Oracle WebLogic CVE-2024-21182 ถูกใช้โจมตีจริง

- สรุป: CISA เพิ่ม CVE-2024-21182 ของ Oracle WebLogic Server เข้า Known Exploited Vulnerabilities Catalog หลังพบหลักฐานการใช้งานจริง ช่องโหว่นี้กระทบ WebLogic Server 12.2.1.4.0 และ 14.1.1.0.0 ซึ่งเป็น Java application server สำหรับระบบ enterprise ผู้โจมตีที่ไม่ต้องมีสิทธิ์สามารถโจมตีผ่านเครือข่ายด้วย T3/IIOP และอาจเข้าถึงข้อมูลสำคัญหรือข้อมูลทั้งหมดที่ WebLogic เข้าถึงได้ แหล่งข่าวยังระบุว่ามี WebLogic ที่เปิดสู่อินเทอร์เน็ตและยังเสี่ยงอยู่จำนวนมาก
- CVE: CVE-2024-21182
- รูปแบบการโจมตี: remote unauthenticated exploitation ต่อ Java middleware / Oracle WebLogic ผ่าน T3/IIOP
- การดำเนินการที่แนะนำ: แพตช์ WebLogic ตามคำแนะนำของ Oracle ทันที, จำกัดการเข้าถึง T3/IIOP จากอินเทอร์เน็ต, ตรวจ IOC/ล็อกการเชื่อมต่อผิดปกติไปยัง WebLogic, ตรวจ inventory เวอร์ชัน 12.2.1.4.0 และ 14.1.1.0.0 และปิดหรือแยกระบบที่ยังแก้ไม่ได้
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-orders-feds-to-patch-actively-exploited-oracle-weblogic-flaw/)

### 🔴 High — ชุดเครื่องมือ ransomware ที่ใช้ AI ช่วยพัฒนา เร่ง EDR evasion และ Active Directory discovery

- สรุป: Sophos พบชุดเครื่องมือที่เกี่ยวข้องกับปฏิบัติการ ransomware ซึ่งใช้ AI coding agents ช่วยพัฒนา payload, ทดสอบเทคนิคหลบเลี่ยง EDR และทำ Active Directory discovery ในแล็บ เครื่องมือมีองค์ประกอบสำหรับ Cobalt Strike profile, Telegram-based C2, Cloudflare Worker redirector และสคริปต์ Python สำหรับฝัง shellcode ใน executable ของ Windows ข้อมูลชี้ว่า AI ไม่ได้ทำงานเองในเครื่องเหยื่อ แต่ช่วยเร่งรอบการพัฒนาและทดสอบ malware ให้ bypass EDR ได้เร็วขึ้น
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: ransomware post-exploitation tooling, Windows payload loader generation, EDR evasion, Active Directory discovery และ C2 obfuscation
- การดำเนินการที่แนะนำ: เพิ่มการตรวจจับ Cobalt Strike profile ที่ปลอมเป็น traffic ปกติ, เฝ้าระวัง Telegram Bot API/Cloudflare Worker ที่ใช้เป็น C2 relay, ตรวจ executable/DLL ที่ถูกสร้างหรือแก้ไขใน user profile, ทบทวน AD discovery telemetry และทดสอบ EDR rule กับ payload ที่มี Rust/Go loader และ Python injector
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/ai-built-ransomware-toolkit-automates-edr-evasion-ad-discovery/)

## Medium

### 🟡 Medium — Gamaredon ใช้ช่องโหว่ WinRAR ส่ง GammaWorm และ GammaSteel บน Windows

- สรุป: The Hacker News รายงานว่า Gamaredon ยังคงใช้ CVE-2025-8088 ใน WinRAR เพื่อส่ง GammaPhish, GammaLoad, GammaWorm และ GammaSteel ในแคมเปญโจมตียูเครน ห่วงโซ่โจมตีใช้ VBScript, Windows LNK, scheduled tasks, registry configuration และ NTFS Alternate Data Streams เพื่อ persistence/หลบซ่อน โดย GammaSteel ทำหน้าที่ขโมยไฟล์และส่งออกไปยัง AWS S3 หรือ server ของผู้โจมตี บริบทเป็นการโจมตีแบบเจาะจง แต่เทคนิคเกี่ยวข้องกับ Windows endpoint โดยตรง
- CVE: CVE-2025-8088
- รูปแบบการโจมตี: spear phishing / weaponized RAR, Windows LNK/VBScript execution, worm propagation, information stealing และ C2 ผ่าน Telegram dead-drop
- การดำเนินการที่แนะนำ: อัปเดต WinRAR และ block archive ที่น่าสงสัยจากอีเมล, ตรวจการรัน `mshta`, `wscript/cscript`, LNK จาก network share/USB, ตรวจ scheduled tasks ที่สร้างใหม่ และเฝ้าระวัง curl/Telegram access ที่ผิดปกติจาก endpoint
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/gamaredon-exploits-winrar-to-deliver.html)

### 🟡 Medium — SideCopy ใช้ ZIP/LNK และ Xeno RAT เจาะหน่วยงานการเงินอัฟกานิสถาน

- สรุป: แคมเปญ Operation XENOFISCAL ของกลุ่ม SideCopy ใช้ spear-phishing ZIP ที่มี Windows Shortcut (LNK) ชื่อไฟล์ภาษา Pashto เพื่อโจมตีหน่วยงานการเงินของอัฟกานิสถาน เมื่อเหยื่อเปิดไฟล์ LNK จะเรียก `mshta.exe` เพื่อดึง HTA จากโดเมนที่ถูก compromise แล้วรัน JavaScript แบบ obfuscated ใน memory ก่อนติดตั้ง Xeno RAT ผ่าน DLL loader และสร้าง persistence ใน registry โดยปลอมตัวเป็น Microsoft Edge แหล่งข่าวยังกล่าวถึงแคมเปญที่เกี่ยวข้องซึ่งใช้ Linux `.desktop` launcher เพื่อโจมตีเป้าหมายทางทหารอินเดีย
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: spear phishing, Windows LNK/HTA execution, DLL loader, registry persistence, remote access trojan และ Linux `.desktop` launcher social engineering
- การดำเนินการที่แนะนำ: บล็อกหรือกักกัน ZIP/LNK จากอีเมลภายนอก, ตรวจ `mshta.exe` ที่โหลด HTA จากอินเทอร์เน็ต, ตรวจ registry persistence ที่ปลอมเป็น Edge, เพิ่ม detection สำหรับ Xeno RAT และจำกัดการรัน `.desktop` launcher ที่ดาวน์โหลดจากแหล่งไม่น่าเชื่อถือบน Linux desktop
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/pakistan-linked-sidecopy-targets.html)

### 🟡 Medium — DriveSurge ยึดเว็บจำนวนมากเพื่อส่ง ClickFix และ FakeUpdate malware

- สรุป: BleepingComputer รายงานว่า DriveSurge ทำแคมเปญ malware distribution ขนาดใหญ่โดย compromise เว็บไซต์จำนวนมากแล้ว redirect ผู้เข้าชมผ่าน zTDS เพื่อเลือก lure แบบ FakeUpdates หรือ ClickFix ตามโปรไฟล์เหยื่อ FakeUpdates ปลอมเป็นอัปเดต browser ส่วน ClickFix หลอกให้ผู้ใช้ copy/run คำสั่งเอง แหล่งข่าวระบุการใช้ PowerShell command บน Windows, fake browser update ที่ดาวน์โหลด ZIP พร้อม DLL/executable และ JavaScript payload ที่เจาะจง macOS ด้วย ความเสี่ยงหลักคือ initial access ที่นำไปสู่ payload ถัดไป
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: compromised-site redirect, traffic distribution system, ClickFix social engineering, FakeUpdates, PowerShell execution และ malware pay-per-install
- การดำเนินการที่แนะนำ: บล็อกโดเมน redirect/injection ที่พบ, เพิ่ม user awareness ห้ามรันคำสั่งจากหน้าเว็บ, ตรวจ PowerShell ที่เริ่มจาก browser process, จำกัดการดาวน์โหลด executable/ZIP จากเว็บที่ไม่เชื่อถือ และตรวจ JavaScript injection pattern เช่น `t.js?site=<id>` บนเว็บที่องค์กรดูแล
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-hijack-thousands-of-sites-for-clickfix-and-fakeupdate-attacks/)
