## Critical

### 🚨 Microsoft Patch Tuesday เดือนมิถุนายนแก้ 206 ช่องโหว่ รวม Windows Kernel และ HTTP.sys RCE

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/microsoft-patches-record-206-flaws.html)
- สรุป: Microsoft ออกแพตช์เดือนมิถุนายน 2026 แก้ 206 ช่องโหว่ใน Windows และซอฟต์แวร์ที่เกี่ยวข้อง โดยมี 39 รายการระดับ Critical และมีช่องโหว่ที่ถูกเปิดเผยต่อสาธารณะแล้ว 3 รายการ จุดที่ควรเร่งจัดลำดับคือ Windows Kernel use-after-free ที่อาจทำให้โจมตีแบบ remote code execution ผ่าน network traffic ได้, Windows HTTP.sys RCE และ Windows DHCP Client RCE ข่าวนี้เกี่ยวข้องโดยตรงกับ Windows และ Windows Server ที่เปิดบริการเครือข่ายหรือระบบที่ต้องรับ traffic จากผู้ใช้จำนวนมาก
- CVE: CVE-2026-45657, CVE-2026-47291, CVE-2026-44815, CVE-2025-10263, CVE-2026-8863
- รูปแบบการโจมตี: remote code execution, privilege escalation, security feature bypass, network-facing Windows service exploitation
- การดำเนินการที่แนะนำ: เร่งติดตั้ง June 2026 Security Updates โดยจัดลำดับ Windows Server และเครื่องที่เปิดบริการ HTTP.sys/DHCP หรือรับ traffic จากเครือข่ายก่อน, ตรวจสอบการ reboot หลังแพตช์, สำรองข้อมูลก่อนอัปเดต และเฝ้าระวัง exploit public disclosure ที่อาจถูก weaponize เร็ว

### 🚨 Ivanti, Fortinet และ SAP ออกแพตช์ช่องโหว่ Critical รวม unauthenticated root RCE และ SAP auth bypass

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/ivanti-fortinet-and-sap-release-patches.html)
- สรุป: Fortinet แก้ CVE-2026-25089 ใน FortiSandbox/FortiSandbox Cloud/FortiSandbox PaaS WEB UI ซึ่งเป็น OS command injection จาก crafted HTTP request, Ivanti แก้ Sentry CVE-2026-10520 ที่เปิดทางให้ผู้โจมตี unauthenticated รันโค้ดระดับ root และ CVE-2026-10523 ที่สร้างบัญชี admin ได้, ส่วน SAP แก้ช่องโหว่ Critical ใน NetWeaver AS ABAP, ABAP Platform, Commerce Cloud/Data Hub และ NetWeaver Application Server Java Web Container แม้ข่าวระบุว่ายังไม่พบการโจมตีจริง แต่ผลกระทบเป็นระบบ gateway, sandbox และ enterprise Java/ABAP ที่มีสิทธิสูง
- CVE: CVE-2026-25089, CVE-2026-10520, CVE-2026-10523, CVE-2026-44748, CVE-2026-27671, CVE-2026-22732, CVE-2026-40128
- รูปแบบการโจมตี: unauthenticated remote code execution, OS command injection, authentication bypass, directory traversal, enterprise application compromise
- การดำเนินการที่แนะนำ: อัปเดต FortiSandbox, Ivanti Sentry และ SAP ตาม advisory ล่าสุดทันที, จำกัด internet exposure ของ management/web endpoints, ตรวจ log สำหรับ crafted HTTP request และการสร้าง admin account ผิดปกติ, และทบทวน SAML/RFC/Web Container hardening ใน SAP

## High

### ⚠️ Microsoft Defender “RoguePlanet” zero-day PoC ให้สิทธิ SYSTEM บน Windows ที่อัปเดตแล้ว

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/microsoft-defender-rogueplanet-zero-day.html)
- สรุป: นักวิจัยที่ใช้ชื่อ Chaotic Eclipse/Nightmare-Eclipse เผยแพร่ proof-of-concept สำหรับ Microsoft Defender zero-day ชื่อ RoguePlanet ซึ่งเป็น race condition ที่เมื่อสำเร็จจะได้ shell สิทธิ SYSTEM ข่าวระบุว่าทดสอบกับ Windows 10 และ Windows 11 ที่ติดตั้ง June 2026 Patch Tuesday แล้ว และแม้ PoC ปัจจุบันยังใช้ไม่ได้กับ Windows Server ในรูปแบบเดิม แต่ผู้เผยแพร่ระบุว่าตัวช่องโหว่ยังเกี่ยวข้องกับ Server ได้หากปรับ exploit
- CVE: ไม่พบในข่าว
- รูปแบบการโจมตี: local privilege escalation, public PoC, Windows Defender bypass/abuse, SYSTEM privilege gain
- การดำเนินการที่แนะนำ: ติดตาม Microsoft Defender intelligence/security update อย่างใกล้ชิด, จำกัดสิทธิ local user และ execution policy บน endpoint, monitor การ mount ISO หรือพฤติกรรม exploit chain ที่เกี่ยวกับ Defender, และเพิ่ม EDR rule สำหรับ process ที่ยกระดับสิทธิผิดปกติหลัง Defender interaction

### ⚠️ Exchange Server CVE-2026-42897 ถูกใช้โจมตีผ่าน OWA XSS ก่อนแพตช์

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-patches-exchange-server-zero-day-exploited-in-attacks/)
- สรุป: Microsoft แพตช์ CVE-2026-42897 ใน Exchange Server 2016, Exchange Server 2019 และ Exchange Server Subscription Edition หลังมีการโจมตีจริง ช่องโหว่นี้เป็น spoofing/XSS ที่ผู้โจมตีส่งอีเมล crafted ไปยังผู้ใช้ และเมื่อเปิดผ่าน Outlook Web Access ภายใต้เงื่อนไขบางอย่างจะรัน JavaScript ใน browser context ได้ Microsoft เคยเปิด mitigation ชั่วคราวผ่าน Exchange Emergency Mitigation Service แล้ว แต่ยังแนะนำให้ติดตั้ง June 2026 Security Updates โดยเร็ว
- CVE: CVE-2026-42897
- รูปแบบการโจมตี: exploited zero-day, cross-site scripting, crafted email, Outlook Web Access targeting, Exchange Server compromise path
- การดำเนินการที่แนะนำ: ติดตั้ง Exchange Server June 2026 Security Updates, เปิดและคง Exchange Emergency Mitigation Service mitigation ไว้, ตรวจ mail flow และ OWA access log สำหรับอีเมล/URL ที่ผิดปกติ, และแจ้งผู้ใช้กลุ่มเสี่ยงให้ระวังอีเมลที่ต้องเปิดผ่าน OWA

### ⚠️ Proto6 ใน protobuf.js กระทบ Node.js apps เสี่ยง RCE และ DoS

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/six-proto6-vulnerabilities-in.html)
- สรุป: นักวิจัยรายงานช่องโหว่ 6 รายการใน protobuf.js ซึ่งเป็น JavaScript/TypeScript implementation ของ Protocol Buffers กระทบ Node.js applications, Google Cloud client libraries, messaging frameworks และ CI/CD pipelines ที่ deserialize Protobuf หรือ generate code จาก schema ผู้โจมตีอาจใช้ malicious schema, descriptor หรือ payload เพื่อทำให้ service ล่ม, runtime corruption หรือ code execution ได้ โดยยังไม่พบหลักฐาน active exploitation ในข่าวนี้
- CVE: CVE-2026-44289, CVE-2026-44290, CVE-2026-44291, CVE-2026-44292, CVE-2026-44294, CVE-2026-44295
- รูปแบบการโจมตี: Node.js library vulnerability, remote code execution, denial of service, prototype pollution/code generation abuse, CI/CD payload risk
- การดำเนินการที่แนะนำ: ระบุบริการที่ใช้ protobuf.js และไลบรารีที่พึ่งพาแบบ transitive, อัปเดตแพ็กเกจเมื่อ maintainer ออกเวอร์ชันแก้ไข, จำกัดการรับ schema/descriptor จากแหล่งไม่เชื่อถือ, เพิ่ม validation/fuzz test สำหรับ Protobuf input และ monitor crash loop ใน Node.js services

### ⚠️ Miasma worm source code หลุดบน GitHub เพิ่มความเสี่ยง supply-chain ต่อ npm, PyPI และ CI/CD

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/the-miasma-worm-source-code-briefly-leaked-on-github/)
- สรุป: Source code ของ Miasma credential-stealing framework ถูกเผยแพร่ชั่วคราวบน GitHub ผ่านบัญชีนักพัฒนาที่ถูก compromise โดย Miasma เป็นวิวัฒนาการของ Shai-Hulud ที่ขโมย credential จากเครื่องนักพัฒนา, cloud, CI/CD, Kubernetes, secret stores และใช้ credential ไป compromise repository/package ต่อ ข่าวระบุว่า toolkit ใช้ GitHub เป็น C2, โจมตี ecosystem เช่น npm, PyPI, RubyGems, GitHub Actions และ JFrog Artifactory และมี dead-man switch ที่ลบไฟล์บน Linux/macOS เมื่อ token ถูก revoke
- CVE: ไม่พบในข่าว
- รูปแบบการโจมตี: software supply-chain worm, credential theft, CI/CD compromise, npm/PyPI package poisoning, GitHub token abuse, destructive payload on Linux/macOS
- การดำเนินการที่แนะนำ: rotate GitHub/npm/PyPI/cloud tokens ที่อาจอยู่บนเครื่อง dev หรือ CI, บังคับใช้ least privilege และ short-lived tokens, pin dependency versions และหน่วงเวลารับ package release ใหม่, ตรวจ repository แปลกปลอมหรือ GitHub Actions workflow ที่ถูกเพิ่มเอง, และ isolate build/test environment สำหรับ dependency ใหม่

## Medium

### ℹ️ GitHub เตรียมเปลี่ยน npm v12 เพื่อลดการรันสคริปต์อัตโนมัติระหว่าง `npm install`

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/github-announces-npm-security-changes-to-tackle-supply-chain-attacks/)
- สรุป: GitHub ประกาศว่า npm v12 ซึ่งคาดว่าจะออกเดือนหน้า จะเปลี่ยน default ด้านความปลอดภัยเพื่อลด supply-chain attack ผ่าน `npm install` โดย dependency lifecycle scripts เช่น preinstall/install/postinstall, native module build ผ่าน node-gyp, prepare scripts จาก Git/local/linked dependencies, Git dependencies และ remote URL tarballs จะต้องได้รับการอนุญาตชัดเจนก่อน ข่าวนี้ไม่ใช่เหตุโจมตีโดยตรง แต่เป็นการเปลี่ยนแปลงที่ทีม Node.js/npm ควรวางแผนทดสอบ เพราะอาจกระทบ build pipeline เดิม
- CVE: ไม่พบในข่าว
- รูปแบบการโจมตี: supply-chain hardening, npm install script abuse prevention, dependency execution control
- การดำเนินการที่แนะนำ: ทดสอบ npm v12 กับ project และ CI/CD pipeline ล่วงหน้า, inventory dependency ที่ต้องใช้ lifecycle script หรือ Git/remote URL dependency, สร้าง allowlist เฉพาะที่จำเป็น, และปรับเอกสาร build เพื่อไม่ให้ทีม bypass control ด้วย workaround ที่เสี่ยง
