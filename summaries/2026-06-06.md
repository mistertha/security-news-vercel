## Critical

### 🔴 Critical — Everest Forms Pro WordPress plugin ถูกโจมตีผ่าน RCE ใน PHP

- สรุป: The Hacker News รายงานว่าผู้โจมตีกำลัง exploit ช่องโหว่ CVE-2026-3300 ใน Everest Forms Pro ซึ่งเป็น WordPress plugin ที่มีการติดตั้งราว 4,000 ไซต์ ช่องโหว่นี้เกิดจากฟังก์ชันใน Calculation Addon ต่อค่า input ของผู้ใช้เข้าเป็นโค้ด PHP แล้วส่งเข้า `eval()` โดย escape ไม่เพียงพอ ทำให้ผู้โจมตีที่ไม่ต้องยืนยันตัวตนสามารถรันโค้ด PHP บนเซิร์ฟเวอร์ได้ แหล่งข่าวระบุว่าพบการโจมตีตั้งแต่ 13 เมษายน 2026 และมีความพยายาม exploit มากกว่า 29,300 ครั้ง
- CVE: CVE-2026-3300
- รูปแบบการโจมตี: unauthenticated PHP remote code execution, WordPress plugin exploitation, web shell deployment และการสร้างบัญชี administrator ปลอม
- การดำเนินการที่แนะนำ: อัปเดต Everest Forms Pro เป็น 1.9.13 หรือใหม่กว่า, ตรวจไซต์ที่ใช้ Complex Calculation feature, ค้นหาบัญชี admin แปลกปลอมเช่นชื่อ `diksimarina`, ตรวจ web shell และ PHP file ที่เปลี่ยนแปลงผิดปกติ, และเพิ่ม WAF/virtual patch สำหรับ payload ที่พยายาม inject PHP code
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/hackers-exploit-critical-everest-forms.html)

## High

### 🟠 High — IronWorm และ Miasma ระลอกใหม่โจมตี npm supply chain และขโมย secret จาก developer/CI

- สรุป: The Hacker News รายงานว่า npm ecosystem ถูกโจมตีหลายระลอก โดย IronWorm ใช้แพ็กเกจ npm ที่ถูก trojanize เพื่อกระจาย Rust-based infostealer ที่ขโมย environment variable และไฟล์ credential จำนวนมาก รวมถึง OpenAI Codex, Anthropic/Claude, Google Gemini, AWS, Docker, Kubernetes, npm, Vault, SSH และ wallet บางชนิด มัลแวร์ใช้ preinstall hook, ใช้ GitHub Actions artifact เพื่อขโมย secret และมี eBPF payload สำหรับซ่อน process บน Linux ขณะเดียวกัน Miasma variant ใหม่กระทบ 57 npm packages และใช้เทคนิค Phantom Gyp ผ่าน `binding.gyp` เพื่อหลบการตรวจ install-script ปกติ รวมถึงฝัง persistence ในโปรเจกต์ที่เปิดด้วย AI-assisted IDE
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: npm supply-chain worm, credential theft, CI/CD secret harvesting, trusted publishing abuse, GitHub Actions artifact abuse, Rust malware และ Linux eBPF rootkit
- การดำเนินการที่แนะนำ: ตรวจ dependency tree และ lockfile สำหรับแพ็กเกจ/เวอร์ชันที่ JFrog, StepSecurity, Endor Labs และ OX Security ระบุ, ปิด install scripts/native rebuilds โดยค่าเริ่มต้นเมื่อทำได้, pin package ด้วย integrity hash, rotate npm/GitHub/cloud/SSH/CI secrets ของ developer และ runner ที่อาจติดตั้งแพ็กเกจเสี่ยง, และเพิ่ม detection สำหรับ `binding.gyp`, preinstall hook, Bun runtime download และ GitHub Actions artifact ที่บรรจุ secret
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/ironworm-and-new-miasma-worm-variant.html)

### 🟠 High — OP-512 มุ่งเป้า Microsoft IIS บน Windows Server ด้วย web shell framework เฉพาะทาง

- สรุป: The Hacker News รายงาน threat cluster ใหม่ชื่อ OP-512 ที่มุ่งเป้า Microsoft IIS server เพื่อ deploy custom web shell framework สำหรับ remote access และหลบการตรวจจับ ReliaQuest ประเมินว่ากิจกรรมนี้น่าจะเชื่อมโยงกับจีนในระดับ moderate to high confidence เคสที่สังเกตพบเกี่ยวข้องกับ legacy IIS server บน Windows Server 2016 และ .NET Framework 4.0 โดยผู้โจมตีใช้ worker process `w3wp.exe` วาง web shell ใน upload directory และใช้เทคนิค timestomping เพื่อทำให้ artifact ดูเหมือนอยู่ในระบบมานานแล้ว
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: IIS web shell deployment, cyber espionage, timestomping, authenticated command execution และ C2 self-reporting ผ่าน DNS/HTTP
- การดำเนินการที่แนะนำ: ตรวจ IIS upload directory และ web root สำหรับไฟล์แปลกปลอม, hunt process tree ที่เริ่มจาก `w3wp.exe` แล้วเขียนไฟล์หรือรันคำสั่ง, ตรวจ timestamp ที่สอดคล้องผิดปกติรอบ web shell, อัปเกรดหรือ retire Windows Server/IIS/.NET ที่ legacy, จำกัดสิทธิ์ write ของ application pool และเพิ่ม logging สำหรับ outbound DNS/HTTP callback จาก web server
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/new-threat-cluster-op-512-targets.html)

### 🟠 High — CISA เตือน SolarWinds Serv-U บน Windows/Linux ถูก exploit เพื่อทำ DoS

- สรุป: BleepingComputer รายงานว่า CISA เพิ่ม CVE-2026-28318 ของ SolarWinds Serv-U เข้า Known Exploited Vulnerabilities Catalog หลังพบการ exploit ในป่า Serv-U เป็นซอฟต์แวร์ file transfer สำหรับ Windows และ Linux ที่ให้บริการ MFT/FTP/FTPS/SFTP/HTTP(S) ช่องโหว่นี้เป็น uncontrolled resource consumption ที่ทำให้ service crash ได้จาก POST request ที่ crafted แบบไม่ต้องยืนยันตัวตน SolarWinds ออก Serv-U 15.5.4 Hotfix 1 แล้ว และ CISA กำหนดให้หน่วยงาน FCEB แก้ไขภายใน 19 มิถุนายน 2026
- CVE: CVE-2026-28318
- รูปแบบการโจมตี: unauthenticated denial-of-service ต่อ internet-facing file transfer server, active exploitation และ resource consumption ผ่าน crafted POST request พร้อม `Content-Encoding: deflate`
- การดำเนินการที่แนะนำ: อัปเดต SolarWinds Serv-U เป็น 15.5.4 Hotfix 1, จำกัดการเข้าถึง Serv-U ให้เฉพาะ IP ที่รู้จัก, block POST request ที่มี header `content-encoding` ตามคำแนะนำ vendor หากยัง patch ไม่ได้, ตรวจ log สำหรับ request ลักษณะดังกล่าว และจัดลำดับ patch สูงให้ระบบ Serv-U ที่เปิดสู่อินเทอร์เน็ต
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-hackers-now-exploit-solarwinds-serv-u-flaw-to-crash-servers/)

### 🟠 High — PCPJack hijack AWS, GCP และ Azure servers เพื่อสร้าง SMTP relay network

- สรุป: The Hacker News รายงานว่า threat actor ชื่อ PCPJack hijack cloud servers บน AWS, Google Cloud และ Microsoft Azure ประมาณ 230 เครื่อง เพื่อแปลงเป็น SMTP proxy/relay network แบบ covert Hunt.io พบ source code, binary, deployment log, scanner, exploitation tooling และ Sliver configuration บน C2 ที่เปิด directory ทิ้งไว้ เครื่องเหยื่อมี binary สำหรับ Linux หลาย architecture เช่น AMD64, ARM64 และ x86 โดย drop เป็นไฟล์ซ่อนใน `/var/tmp/.xs`, ใช้ Chisel tunnel, ตรวจ outbound SMTP ไป `smtp.gmail[.]com:587` และ sync proxy list ทุก 5 นาทีไป downstream server
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: cloud server compromise, Sliver C2, Linux persistence, Chisel tunneling, SMTP relay abuse และ opportunistic infrastructure hijacking
- การดำเนินการที่แนะนำ: ตรวจ cloud workload บน AWS/GCP/Azure สำหรับ Sliver beacon, Chisel process, ไฟล์หรือ service แปลกปลอมใน `/var/tmp/.xs`, outbound SMTP ที่ไม่สอดคล้องกับหน้าที่เครื่อง, cron/systemd persistence และ traffic ไป C2/ปลายทาง sync ที่แหล่งข่าวระบุ; ปิด outbound SMTP โดย default สำหรับ workload ที่ไม่จำเป็นและ rotate credential ของ instance ที่พบสัญญาณ compromise
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/pcpjack-hijacks-230-aws-google-cloud.html)
