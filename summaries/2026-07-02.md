## Critical

### 🚨 CISA: Microsoft Defender BlueHammer ถูกใช้ใน ransomware attacks

- **สรุป:** CISA มี alert วันที่ 2026-07-01 เรื่องการเพิ่มช่องโหว่ที่ถูก exploit แล้วหนึ่งรายการใน KEV catalog และผลค้นหาที่เกี่ยวข้องระบุว่าเป็น BlueHammer ใน Microsoft Defender ซึ่งถูกใช้โดย ransomware เพื่อยกระดับสิทธิ์เป็น SYSTEM บน Windows หลักฐานจากหน้า CISA โดยตรงมีจำกัดเพราะ runtime ได้รับ 403 เมื่อเปิดรายละเอียด แต่หัวข้อ alert และข่าวที่เกี่ยวข้องชี้ว่าควรเร่งจัดการในฝั่ง Windows endpoint
- **CVE:** CVE-2026-33825
- **Attack type:** Local privilege escalation / ransomware post-exploitation
- **Recommended action:** ตรวจสอบสถานะ patch/Defender platform update บน Windows endpoint และ server, เร่งจัดลำดับ remediation สำหรับเครื่องที่ถูกใช้โดยผู้ใช้สิทธิ์สูงหรือมี exposure ต่อ malware, และตรวจหา IOC/พฤติกรรม ransomware ที่พยายามยกระดับสิทธิ์ผ่าน Defender
- **Source:** https://www.cisa.gov/news-events/alerts/2026/07/01/cisa-adds-one-known-exploited-vulnerability-catalog

## High

### 🐍 ChocoPoC RAT แฝงผ่าน dependency ของ PoC exploit บน GitHub/PyPI

- **สรุป:** BleepingComputer รายงานแคมเปญที่ใช้ repository PoC exploit ปลอมบน GitHub เพื่อล่อให้นักวิจัยหรือผู้ทดสอบ clone โค้ด จากนั้น dependency ของ Python จะดึง package อันตรายจาก PyPI เช่น `frint` และ `skytext` เพื่อติดตั้ง ChocoPoC RAT ที่รันคำสั่ง, ขโมยข้อมูล browser, เก็บ shell history, อัปโหลดไฟล์ และสำรวจระบบได้ จุดเสี่ยงอยู่ที่ supply chain ของ Python/pip และพฤติกรรมการรัน PoC จากแหล่งที่ยังไม่ตรวจสอบ
- **CVE:** CVE-2025-64446, CVE-2025-55182, CVE-2025-14847, CVE-2026-0257, CVE-2026-10520, CVE-2026-50751, CVE-2026-48908
- **Attack type:** Python package supply-chain malware / trojanized PoC
- **Recommended action:** ห้ามรัน PoC บนเครื่องทำงานจริง, ใช้ sandbox/container แยกขาด, pin และตรวจ dependency ก่อนติดตั้ง, block/monitor package และ repository ที่เกี่ยวข้อง, และทบทวน token/credential บนเครื่องที่เคยทดสอบ PoC น่าสงสัย
- **Source:** https://www.bleepingcomputer.com/news/security/chocopoc-malware-delivered-via-trojanized-exploits-on-github/

## Medium

### 🪟 Ousaban banking trojan มุ่งเป้า Windows users ในสเปนและโปรตุเกส

- **สรุป:** The Hacker News รายงาน Ousaban banking trojan ที่โจมตีผู้ใช้ Windows ผ่าน phishing PDF ปลอมเป็นไฟล์เสียหาย ก่อนซ่อน payload ในรูปภาพและรอขโมยข้อมูลเมื่อเหยื่อเปิดเว็บธนาคาร เป้าหมายหลักคือการยึด banking session ผ่าน screenshot, keylogging, clipboard tampering, fake messages และ remote control
- **CVE:** ไม่พบในแหล่งข่าว
- **Attack type:** Phishing / Windows banking trojan / credential theft
- **Recommended action:** บล็อก execution ของ script จากไฟล์แนบที่ไม่น่าเชื่อถือ, ตรวจจับ PowerShell/loader ที่ตามหลัง PDF lure, เปิดใช้ EDR rule สำหรับ banking trojan behavior, และให้ผู้ใช้รายงานไฟล์ PDF ที่อ้างว่าเสียหายหรือให้เปิดซ้ำผ่าน browser
- **Source:** https://thehackernews.com/2026/07/ousaban-banking-trojan-targets-iberian.html

### 🧾 VEIL#DROP ใช้ JavaScript ปลอมเป็น PDF และ PowerShell บน Windows เพื่อส่ง PureLogs Stealer

- **สรุป:** The Hacker News รายงาน chain แบบหลายขั้นที่เริ่มจากไฟล์ JavaScript ชื่อเหมือนเอกสาร เช่น `transcript.pdf.js` เมื่อรันผ่าน Windows Script Host จะเรียก PowerShell แบบ bypass policy เพื่อดึง payload จาก Blogger และติดตั้ง PureLogs Stealer ซึ่งเป็น .NET infostealer สำหรับขโมยข้อมูลจาก host
- **CVE:** ไม่พบในแหล่งข่าว
- **Attack type:** Social engineering / Windows Script Host / PowerShell downloader / infostealer
- **Recommended action:** ซ่อน/บล็อก double-extension ที่เสี่ยง, จำกัด Windows Script Host ตามความจำเป็น, alert เมื่อ PowerShell ถูกเรียกจาก `wscript.exe` หรือ `cscript.exe`, และตรวจ traffic ไปยัง Blogger/บริการ trusted hosting ที่ผิดปกติจาก endpoint
- **Source:** https://thehackernews.com/2026/07/veildrop-malware-chain-uses-blogger.html

### 🧩 SEO-poisoned software sites ใช้ DLL side-loading และ ScreenConnect เพื่อ deploy AsyncRAT

- **สรุป:** The Hacker News รายงานแคมเปญ SEO poisoning ที่ทำเว็บปลอมสำหรับซอฟต์แวร์ยอดนิยม แล้วแจก archive ที่มี Microsoft `install.exe` ที่ถูกต้องพร้อม DLL ปลอม `install.res.1033.dll` เพื่อทำ DLL side-loading และติดตั้ง ScreenConnect สำหรับรอคำสั่งก่อน deploy AsyncRAT รูปแบบนี้กระทบ Windows endpoint ที่ผู้ใช้ดาวน์โหลด installer จาก search result ที่ถูกปั่นอันดับ
- **CVE:** ไม่พบในแหล่งข่าว
- **Attack type:** SEO poisoning / DLL side-loading / remote access trojan
- **Recommended action:** บังคับดาวน์โหลดซอฟต์แวร์จาก allowlisted domains, ตรวจจับ ScreenConnect installation ที่ไม่ได้รับอนุมัติ, alert DLL side-loading จาก path ชั่วคราวหรือ archive extraction, และใช้ application control กับ installer ที่ผู้ใช้ดาวน์โหลดเอง
- **Source:** https://thehackernews.com/2026/07/seo-poisoned-software-sites-abuse.html

### 🌐 AI-generated browser ransomware technique กระทบ Chromium-based browsers บน Windows และ Android

- **สรุป:** The Hacker News รายงานตัวอย่าง malware ที่ใช้แนวคิด in-browser ransomware ผ่าน Chromium File System Access API บน Windows และ Android โดยตัวอย่างเป็น Python Flask app ที่ล่อผู้ใช้ด้วยเว็บปลอมและรวมความสามารถขโมย token, seed phrase, keylogging, webcam/microphone capture และ WinLocker อย่างไรก็ตามแหล่งข่าวระบุว่ายังไม่มีหลักฐานว่าเทคนิค browser-native ransomware นี้ถูกใช้จริงในวงกว้าง
- **CVE:** มีการกล่าวถึง CVE-2023-4863 ในบริบท browser exploitation routine
- **Attack type:** Browser-based ransomware concept / credential theft / malicious web app
- **Recommended action:** จำกัดการใช้ browser API เสี่ยงใน enterprise policy เท่าที่ทำได้, block URL/attachment ที่รัน local malicious web app, monitor Python Flask process ที่เปิดจาก user profile, และเตือนผู้ใช้ไม่ให้รันเครื่องมือ AI/avatar/upscaler จากแหล่งไม่น่าเชื่อถือ
- **Source:** https://thehackernews.com/2026/07/ai-generated-browser-ransomware-abuses.html
