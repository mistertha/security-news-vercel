## Critical

### 🔴 Critical — Everest Forms Pro ถูกโจมตีผ่าน PHP RCE เพื่อยึด WordPress sites

- สรุป: BleepingComputer รายงานว่าผู้โจมตีกำลัง exploit CVE-2026-3300 ใน Everest Forms Pro เวอร์ชัน 1.9.12 และเก่ากว่า ซึ่งเป็น commercial add-on ของ WordPress plugin Everest Forms ช่องโหว่อยู่ใน Complex Calculation feature ที่นำค่าจาก form field ไปต่อเป็นสตริงโค้ด PHP แล้วรันผ่าน `eval()` โดย escape บริบท PHP ไม่เพียงพอ ทำให้ผู้โจมตีที่ไม่ต้องยืนยันตัวตนสามารถ inject และรัน PHP บนเซิร์ฟเวอร์ได้ Wordfence telemetry ระบุว่ามีการโจมตีจริงเพื่อสร้างบัญชี administrator ปลอม และเริ่มพบ exploitation ตั้งแต่ 13 เมษายน 2026 พร้อมความพยายามมากกว่า 29,300 ครั้ง
- CVE: CVE-2026-3300
- รูปแบบการโจมตี: unauthenticated PHP remote code execution, WordPress plugin exploitation, rogue administrator creation, web shell/backdoor deployment
- การดำเนินการที่แนะนำ: อัปเดต Everest Forms Pro เป็นเวอร์ชันที่แก้ไขแล้ว 1.9.13 หรือใหม่กว่า, ตรวจบัญชี administrator แปลกปลอมโดยเฉพาะชื่อ `diksimarina`, ตรวจ web root และ plugin/theme files สำหรับ backdoor, review access/error logs รอบ form submission ที่ผิดปกติ, และ block IOC/IP ที่ Wordfence ระบุหากยัง patch ไม่ครบ
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-everest-forms-pro-flaw-exploited-to-take-over-wordpress-sites/)

## High

### 🟠 High — Miasma worm กระทบ Microsoft/Azure GitHub repositories และตอกย้ำความเสี่ยง supply chain ของ npm/PyPI

- สรุป: The Hacker News รายงานว่า Miasma self-replicating supply-chain campaign กระทบ 73 repositories ใน GitHub organizations ของ Microsoft รวมถึง Azure, Azure-Samples, Microsoft และ MicrosoftDocs โดย GitHub ต้อง disable access ต่อ repositories ที่เกี่ยวข้อง รายงานระบุว่าบางส่วนอยู่ใน ecosystem ที่เกี่ยวข้องกับ Azure Functions, Durable Task, .NET, Go, Java และ JavaScript และมีการ re-compromise ของ `durabletask` PyPI package ที่เคยถูกใช้ส่ง infostealer บน Linux ก่อนหน้า แคมเปญนี้ยังถูกสังเกตว่าขยับจาก npm registry poisoning ไปสู่การฝัง payload runner ใน source repositories เพื่อให้ทำงานเมื่อ developer clone repo และเปิดด้วย AI coding tools หรือรัน npm test
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: software supply-chain worm, credential/maintainer compromise, npm/PyPI package abuse, GitHub repository compromise, developer workstation and CI/CD secret theft
- การดำเนินการที่แนะนำ: ตรวจ dependency และ internal mirrors สำหรับแพ็กเกจ/commit ที่เชื่อมกับ Miasma/Mini Shai-Hulud, block หรือ sandbox install/test scripts ใน CI, rotate GitHub/npm/PyPI/cloud tokens ของ maintainer และ runner ที่อาจสัมผัส repo เสี่ยง, ตรวจ repositories สำหรับ payload runner หรือ workflow แปลกปลอม, และบังคับใช้ provenance/signing plus least-privilege token scopes
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/miasma-worm-hits-73-microsoft-github.html)

### 🟠 High — CISA เพิ่ม SolarWinds Serv-U DoS ที่ถูก exploit แล้วเข้า KEV Catalog

- สรุป: The Hacker News รายงานว่า CISA เพิ่ม CVE-2026-28318 ของ SolarWinds Serv-U multi-protocol file server software เข้า Known Exploited Vulnerabilities Catalog หลังพบ evidence of active exploitation ช่องโหว่นี้เป็น uncontrolled resource consumption/DoS ที่ทำให้ Serv-U service crash ได้จาก crafted POST request แบบไม่ต้องยืนยันตัวตนโดยใช้ `Content-Encoding: deflate` Serv-U เป็นซอฟต์แวร์ file server ที่มักเปิดให้บริการ transfer protocol หลายแบบบน Windows และ Linux จึงควรจัดลำดับระบบที่ internet-facing เป็นพิเศษ แม้แหล่งข่าวยังไม่มีรายละเอียดว่าผู้โจมตีใช้ในโลกจริงอย่างไรหรือมี instance ถูก compromise กี่ราย
- CVE: CVE-2026-28318
- รูปแบบการโจมตี: unauthenticated denial-of-service, active exploitation of internet-facing file transfer server, crafted POST request resource exhaustion
- การดำเนินการที่แนะนำ: อัปเดต SolarWinds Serv-U เป็น 15.5.4 HF1, จำกัดการเข้าถึง Serv-U ให้เฉพาะ source IP ที่เชื่อถือได้, block request ที่มี `content-encoding` ตาม mitigation ของ vendor หากยัง patch ไม่ได้, ตรวจ log สำหรับ POST request ที่มี `Content-Encoding: deflate`, และจัด patch deadline ก่อน 19 มิถุนายน 2026 สำหรับระบบที่เข้าข่าย BOD/KEV-driven remediation
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/cisa-adds-actively-exploited-solarwinds.html)
