## High

### 🔴 High — Redis CVE-2026-23479 เปิดทาง RCE หลังมีรายละเอียด exploit เผยแพร่

- สรุป: Redis แก้ช่องโหว่ use-after-free ในโค้ด blocking-client ที่ทำให้ผู้ใช้ที่ authenticate แล้วสามารถรันคำสั่งระบบปฏิบัติการบนเครื่องที่รัน Redis ได้ ช่องโหว่กระทบ Redis ตั้งแต่ 7.2.0 ในหลาย branch และถูกแก้ใน 7.2.14, 7.4.9, 8.2.6, 8.4.3 และ 8.6.3 แม้ยังไม่มีรายงานการโจมตีจริง แต่ chain ทางเทคนิคถูกเผยแพร่แล้วและหลายสภาพแวดล้อม cloud ใช้ Redis โดยเปิด default user หรือสิทธิ์กว้างเกินจำเป็น
- CVE: CVE-2026-23479
- รูปแบบการโจมตี: authenticated remote code execution ผ่าน Redis ACL/CONFIG/EVAL/stream command chain และ use-after-free
- การดำเนินการที่แนะนำ: อัปเกรด Redis เป็นเวอร์ชันที่แก้แล้วตาม branch, เร่งตรวจ internet-exposed Redis, จำกัด ACL ไม่ให้ role เดียวมี CONFIG, @admin, @scripting และ stream access พร้อมกัน, ปิด Lua scripting หากไม่ใช้ และ rotate credential ที่แชร์กว้าง
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/autonomous-ai-tool-finds-2-year-old-rce.html)

### 🔴 High — HTTP/2 Bomb ทำให้ NGINX, Apache, IIS, Envoy และ Cloudflare Pingora ล่มได้จาก client เดียว

- สรุป: นักวิจัยเผยเทคนิค HTTP/2 Bomb ซึ่งผสม HPACK compression amplification กับ Slowloris-style flow-control hold เพื่อทำให้ web server จัดสรรหน่วยความจำจำนวนมากและไม่คืนหน่วยความจำได้ทันที รายงานระบุว่ากระทบ default HTTP/2 configuration ของ NGINX, Apache HTTP Server, Microsoft IIS, Envoy และ Cloudflare Pingora โดย PoC ถูกเผยแพร่แล้ว และบางผลิตภัณฑ์ยังไม่มี patch ในเวลารายงาน
- CVE: ไม่พบ CVE ใหม่ในแหล่งข่าว; บทความอ้างอิงช่องโหว่/เทคนิคเดิม เช่น CVE-2016-6581, CVE-2025-53020, CVE-2016-8740 และ CVE-2016-1546
- รูปแบบการโจมตี: remote denial-of-service ต่อ HTTP/2 web server ผ่าน HPACK memory amplification และ flow-control stalling
- การดำเนินการที่แนะนำ: อัปเกรด NGINX เป็น 1.29.8+ และ Apache mod_http2 เป็น 2.0.41+, พิจารณาปิด HTTP/2 ชั่วคราวบนระบบสำคัญที่ยังแก้ไม่ได้, จำกัด exposure ของ service ที่รับ HTTP/2 จากอินเทอร์เน็ต และเพิ่ม monitoring memory spike/connection behavior ที่ผิดปกติ
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/new-http2-bomb-vulnerability-allows.html), [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-http-2-bomb-dos-attack-crashes-web-servers-in-under-a-minute/)

### 🔴 High — CISA เพิ่ม Linux cgroups CVE-2022-0492 เข้า KEV หลังพบการโจมตีจริง

- สรุป: CISA เตือนว่ามีการโจมตีช่องโหว่ Linux kernel CVE-2022-0492 ซึ่งเป็น privilege escalation ใน cgroups v1 subsystem ฟังก์ชัน `cgroup_release_agent_write()` ข้อบกพร่องนี้ทำให้ local attacker ข้าม namespace isolation, ยกระดับสิทธิ์ และอาจ escape จาก container ไปยัง host ได้ โดยเสี่ยงมากใน containerized environment ที่ใช้ cgroups v1 หรือ container ที่ได้รับ capability สูงเกินจำเป็น
- CVE: CVE-2022-0492
- รูปแบบการโจมตี: Linux local privilege escalation / container escape ผ่าน cgroups v1
- การดำเนินการที่แนะนำ: ตรวจ kernel version และ patch เป็น branch ที่แก้แล้ว, ลด privileged container/capability ที่ไม่จำเป็น, ปิดหรือเลิกใช้ cgroups v1 เมื่อทำได้, ตรวจ workload ที่รันด้วยสิทธิ์สูง และจัดลำดับแก้ไขระบบ container host ที่ internet-facing หรือรองรับ workload จากหลายทีม
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/security/cisa-warns-of-active-attacks-exploiting-android-linux-bugs/)

## Medium

### 🟡 Medium — Windows Search URI ยังเปิดทางให้ขโมย NTLMv2 hash ได้โดยยังไม่มี patch

- สรุป: นักวิจัยเปิดเผยปัญหาใน Windows `search:` URI handler ที่สามารถบังคับให้เครื่องเหยื่อติดต่อ SMB server ของผู้โจมตีผ่าน `crumb=location:` และทำให้ Net-NTLMv2 hash รั่วได้ เงื่อนไขโจมตีต้องอาศัยการหลอกให้ผู้ใช้คลิกลิงก์ และ Microsoft ระบุว่ายังไม่เข้าเกณฑ์แก้ไขตามระดับความรุนแรง จึงถือเป็นความเสี่ยงต่อการ relay attack ในเครือข่าย Windows ที่ยังพึ่งพา NTLM
- CVE: ไม่พบ CVE ใหม่สำหรับประเด็น `search:` URI; แหล่งข่าวอ้างเทียบกับ CVE-2026-33829 และ CVE-2023-35636
- รูปแบบการโจมตี: credential leakage / NTLM relay ผ่าน Windows URI handler และ outbound SMB
- การดำเนินการที่แนะนำ: บล็อก outbound SMB TCP/445 และ TCP/139 จาก endpoint ที่ไม่จำเป็น, บังคับใช้ SMB signing, ลดหรือปิด NTLM ตามความเหมาะสม, เพิ่ม detection สำหรับ process/browser ที่เรียก `search:` URI ไปยัง UNC path และสื่อสารกับผู้ใช้เรื่องลิงก์ที่เปิด Windows protocol handler
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/unpatched-windows-search-uri.html)
