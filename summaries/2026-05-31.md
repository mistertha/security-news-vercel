### 🔴 Critical — Attackers Use LLM Agent for Post-Exploitation After Marimo CVE-2026-39987 Exploit

- สรุป: The Hacker News รายงานการโจมตีที่เริ่มจากการใช้ช่องโหว่ Marimo ที่เปิดให้เข้าถึงจากอินเทอร์เน็ต แล้วผู้โจมตีใช้ LLM agent ช่วยทำ post-exploitation แบบปรับตัวตามสภาพแวดล้อมจริง มีการดึง cloud credentials, ใช้ SSH key ที่ได้มาเข้าระบบต่อ และขโมยข้อมูลจากฐานข้อมูล PostgreSQL ภายในอย่างรวดเร็ว รายละเอียดมาจากหน้าแหล่งข่าวที่เข้าถึงได้ เนื่องจาก RSS โดยตรงถูกบล็อกจาก runtime
- CVE: CVE-2026-39987
- รูปแบบการโจมตี: pre-auth remote code execution, credential theft, post-exploitation ด้วย LLM agent, database exfiltration
- คำแนะนำ: อัปเดต Marimo เป็นเวอร์ชันล่าสุด ตรวจสอบ instance ที่เปิดสู่สาธารณะ หมุนเวียน cloud/API/SSH credentials ที่อาจเกี่ยวข้อง และตรวจ log ของ PostgreSQL, SSH และ cloud secrets access เพื่อหาพฤติกรรมผิดปกติ
- แหล่งข่าว: https://thehackernews.com/2026/05/attackers-use-llm-agent-for-post.html

### 🟠 High — New CIFSwitch Linux flaw gives root on multiple distributions

- สรุป: BleepingComputer รายงานช่องโหว่ local privilege escalation ใน Linux kernel/CIFS ที่ชื่อ CIFSwitch ทำให้ผู้ใช้สิทธิ์ต่ำสามารถปลอม cifs.spnego key request และทำให้ helper ที่รันด้วยสิทธิ์ root เชื่อข้อมูลที่ควบคุมโดยผู้โจมตี จนนำไปสู่ root code execution ได้ เงื่อนไขขึ้นกับ kernel, cifs-utils, user namespaces และนโยบาย SELinux/AppArmor โดยมี PoC เผยแพร่แล้วและมีหลาย distribution ที่อาจได้รับผลกระทบ รวมถึงบางกรณีของ Ubuntu, Debian, openSUSE, Oracle Linux และ Amazon Linux เมื่อมี cifs-utils
- CVE: ไม่ระบุในแหล่งข่าว
- รูปแบบการโจมตี: local privilege escalation ผ่าน Linux CIFS/cifs-utils และ namespace/NSS abuse
- คำแนะนำ: ติดตามแพตช์ kernel จาก distribution ที่ใช้งาน ปิดหรือ blacklist โมดูล CIFS หากไม่จำเป็น ลบ cifs-utils หากไม่ได้ใช้ และพิจารณาปิด unprivileged user namespaces ในระบบที่มีความเสี่ยง
- แหล่งข่าว: https://www.bleepingcomputer.com/news/security/new-cifswitch-linux-flaw-gives-root-on-multiple-distributions/

### 🟠 High — Malicious Sicoob NuGet Steals Banking Credentials as npm Packages Target Cloud Secrets

- สรุป: The Hacker News รายงาน supply-chain หลายกรณีใน ecosystem ของ NuGet และ npm โดยแพ็กเกจ NuGet ปลอม `Sicoob.Sdk` ขโมย client ID, PFX certificate และข้อมูลธุรกรรม ส่วน npm พบ 14 แพ็กเกจที่ typosquat ชื่อที่เกี่ยวข้องกับ OpenSearch, ElasticSearch, DevOps และ environment configuration เพื่อเก็บ AWS credentials, HashiCorp Vault tokens, npm tokens และ CI/CD secrets ผ่าน preinstall hook เหตุการณ์นี้กระทบโดยตรงต่อทีมที่ใช้ .NET/NuGet, npm และ pipeline อัตโนมัติ
- CVE: ไม่ระบุ
- รูปแบบการโจมตี: software supply chain, package typosquatting, credential and secret theft, preinstall hook abuse
- คำแนะนำ: ตรวจสอบ dependency lockfiles และ package provenance สำหรับ NuGet/npm ลบแพ็กเกจที่ระบุ หมุนเวียน PFX, npm token, CI/CD secret และ cloud credentials ที่อาจรั่ว เปิดใช้ package allowlist และบังคับ secret scanning ใน pipeline
- แหล่งข่าว: https://thehackernews.com/2026/05/malicious-sicoob-nuget-steals-banking.html
