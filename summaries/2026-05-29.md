## Critical

### 🚨 FortiClient EMS CVE-2026-35616 ถูกใช้โจมตีเพื่อกระจาย EKZ Infostealer

ผู้โจมตีกำลังใช้ช่องโหว่ pre-authentication API access bypass ใน FortiClient Endpoint Management Server เพื่อแก้ไขคอนฟิกและสั่งรันสคริปต์บน endpoint ที่ถูกจัดการ โดย payload ถูกปลอมเป็นอัปเดต Fortinet และรันผ่าน PowerShell ก่อนขโมยข้อมูลจากเบราว์เซอร์ Chromium/Firefox เช่น รหัสผ่าน คุกกี้ และข้อมูล autofill ความเสี่ยงสูงเพราะ EMS เป็นช่องทางบริหาร endpoint ที่ได้รับความเชื่อถือและอาจกระทบทั้ง fleet ได้ในครั้งเดียว

- CVE: CVE-2026-35616
- รูปแบบการโจมตี: authentication bypass, privilege escalation, endpoint management abuse, credential theft
- คำแนะนำ: อัปเกรด FortiClient EMS เป็น 7.4.7 หรือใหม่กว่า/ใช้ hotfix ที่ผู้ผลิตออกให้ จำกัดการเข้าถึง EMS จากเครือข่ายที่เชื่อถือได้ ตรวจ log เช่น `Certificate not found in request header` และตรวจการเปลี่ยนแปลง Remote Access Profile หรือ endpoint policy ที่ผิดปกติ
- แหล่งที่มา: https://thehackernews.com/2026/05/threat-actors-exploit-critical.html

### 🚨 Gogs zero-day RCE เปิดทางให้ผู้ใช้ทั่วไปยึดเซิร์ฟเวอร์ได้

มีการเปิดเผยช่องโหว่ argument injection ใน Gogs ซึ่งเป็นบริการ Git แบบ self-hosted โดยผู้ใช้ที่มีบัญชีธรรมดาสามารถสร้าง pull request พร้อมชื่อ branch ที่ฝัง `--exec` เพื่อให้คำสั่งถูกส่งต่อไปยัง `git rebase` และรันโค้ดบนเซิร์ฟเวอร์ได้ หากอินสแตนซ์เปิด registration ตามค่าเริ่มต้น ผู้โจมตีอาจสร้างบัญชีเองและเริ่ม exploit chain ได้โดยไม่ต้องมีสิทธิ์ admin ช่องโหว่นี้ยังไม่มี CVE และยังไม่มีแพตช์ ณ ข้อมูลที่เผยแพร่

- CVE: ยังไม่มี CVE
- รูปแบบการโจมตี: argument injection, authenticated remote code execution, source-code and credential exposure
- คำแนะนำ: ปิด open registration ด้วย `DISABLE_REGISTRATION = true`, จำกัดการสร้าง repository ด้วย `MAX_CREATION_LIMIT = 0`, ตรวจการตั้งค่า rebase merge, จำกัดการเข้าถึงจากอินเทอร์เน็ต และเฝ้าดู HTTP 500 หรือกิจกรรม pull request/rebase ที่ผิดปกติ
- แหล่งที่มา: https://thehackernews.com/2026/05/critical-gogs-rce-vulnerability-lets.html

## High

### ⚠️ Microsoft เตือนความเสี่ยงจากการเผยแพร่ Windows zero-day แบบไม่ประสานงาน

Microsoft ระบุว่าการเผยแพร่รายละเอียดและ proof-of-concept ของช่องโหว่ Windows หลายรายการก่อนการประสานงานกับผู้ผลิตทำให้ลูกค้าเสี่ยงมากขึ้น โดยชุดช่องโหว่ที่กล่าวถึงรวมถึง BlueHammer, RedSun, UnDefend, YellowKey, GreenPlasma และ MiniPlasma ซึ่งบางรายการเกี่ยวข้องกับ Microsoft Defender และ BitLocker และมีบางตัวถูกใช้โจมตีจริงแล้ว ประเด็นนี้เป็นสัญญาณให้ทีม Windows เร่งทบทวน exposure แม้บางช่องโหว่อาจยังไม่มีแพตช์ครบ

- CVE: CVE-2026-33825, CVE-2026-41091, CVE-2026-45498, CVE-2026-45585
- รูปแบบการโจมตี: Windows zero-day disclosure, local privilege escalation, security feature bypass, active exploitation
- คำแนะนำ: ตรวจสถานะการแพตช์ Windows และ Microsoft Defender ล่าสุด ใช้มาตรการลดความเสี่ยงสำหรับ BitLocker/Defender ตาม vendor guidance จำกัดสิทธิ์ผู้ใช้ปลายทาง และเพิ่ม detection สำหรับการรัน exploit/PoC ที่เกี่ยวกับชื่อ BlueHammer, RedSun, UnDefend, YellowKey, GreenPlasma และ MiniPlasma
- แหล่งที่มา: https://thehackernews.com/2026/05/microsoft-slams-public-zero-day.html

### ⚠️ GreyVibe ใช้ AI สร้าง lure และเครื่องมือโจมตี Windows/PowerShell RAT

กลุ่ม GreyVibe ซึ่งน่าจะเชื่อมโยงกับผลประโยชน์รัสเซีย ถูกพบใช้ AI สร้างเนื้อหาหลอกลวงและเครื่องมือ custom หลายชุดเพื่อโจมตีหน่วยงานที่เกี่ยวข้องกับยูเครน แคมเปญมีทั้ง phishing archive, ClickFix/fake CAPTCHA และเว็บไซต์ปลอม โดย payload ที่เกี่ยวข้องกับ Windows ได้แก่ LegionRelay และ PhantomRelay ซึ่งเป็น PowerShell RAT ที่รองรับการขโมยไฟล์ จับภาพหน้าจอ ขโมย credential จากเบราว์เซอร์/แอปสื่อสาร และตั้งค่า RDP

- CVE: ไม่ระบุ
- รูปแบบการโจมตี: spear phishing, ClickFix, PowerShell RAT, credential theft, espionage
- คำแนะนำ: บล็อก/ตรวจจับการรัน PowerShell ที่ดาวน์โหลดหรือโหลดสคริปต์แบบ dynamic, เฝ้าระวัง fake CAPTCHA/ClickFix, ตรวจ endpoint สำหรับพฤติกรรม RDP setup ผิดปกติ และนำ IoC จากรายงาน WithSecure ไปเทียบกับ telemetry ภายใน
- แหล่งที่มา: https://www.bleepingcomputer.com/news/security/greyvibe-hackers-use-chatgpt-gemini-to-power-cyberattacks/
