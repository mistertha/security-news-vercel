## Critical

### 🔴 Oracle PeopleSoft zero-day ถูกใช้โจมตีขโมยข้อมูล

Oracle แจ้งช่องโหว่ใน PeopleSoft PeopleTools ที่เปิดให้ผู้โจมตีจากระยะไกลรันโค้ดได้โดยไม่ต้องยืนยันตัวตน และ BleepingComputer/Mandiant ระบุว่าถูกใช้จริงในแคมเปญ ShinyHunters เพื่อเจาะ PeopleSoft และขโมยข้อมูลจากหลายองค์กร แม้ PeopleSoft ไม่อยู่ในรายการแพลตฟอร์มเป้าหมายโดยตรง แต่บริบทมีการกล่าวถึง WebLogic configuration, Azure-disguised agents และการเคลื่อนย้ายภายในระบบ จึงถือเป็นความเสี่ยงสูงต่อระบบองค์กรที่เชื่อมกับสแต็ก Java/enterprise application

- CVE: CVE-2026-35273
- รูปแบบการโจมตี: unauthenticated RCE, data theft, lateral movement
- คำแนะนำ: จำกัดการเข้าถึง endpoint PeopleSoft ที่เกี่ยวข้องทันที, ใช้ mitigation ของ Oracle, ตรวจ log ที่ `/PSEMHUB/` และ `/PSIGW/HttpListeningConnector`, ตรวจหา webshell/ไฟล์ผิดปกติ และเตรียมแพตช์เมื่อ Oracle ออกตัวแก้ไขถาวร
- แหล่งข่าว: https://www.bleepingcomputer.com/news/security/oracle-mitigates-peoplesoft-zero-day-exploited-in-data-theft-attacks/

### 🔴 Ivanti Sentry CVE-2026-10520 ถูกโจมตีหลังมี PoC สาธารณะ

ผู้โจมตีกำลังสแกนและใช้ช่องโหว่ OS command injection ใน Ivanti Sentry เพื่อรันโค้ดด้วยสิทธิ์ root บนอุปกรณ์ secure mobile gateway ที่เปิดสู่อินเทอร์เน็ต Shadowserver ระบุว่าพบความพยายามโจมตีจำนวนมากจาก public PoC และบาง instance ถูกฝัง backdoor แล้ว ความเสี่ยงอยู่ที่ gateway ประเภทนี้เป็นทางเชื่อมเข้าระบบองค์กรและมักถูกใช้เป็นจุดตั้งต้นในการบุกรุก

- CVE: CVE-2026-10520
- รูปแบบการโจมตี: OS command injection, remote code execution, appliance backdoor
- คำแนะนำ: อัปเดต Ivanti Sentry เป็น R10.5.2, R10.6.2 หรือ R10.7.1 ทันที, จำกัดการเข้าถึง admin interface จากอินเทอร์เน็ต, ตรวจหา backdoor และ IOC หลังแพตช์ เพราะระบบที่ยังไม่แพตช์อาจถูกเจาะแล้ว
- แหล่งข่าว: https://www.bleepingcomputer.com/news/security/max-severity-ivanti-sentry-vulnerability-now-exploited-in-attacks/

## High

### 🟠 Miasma/Shai-Hulud toolkit หลุดและขยายความเสี่ยง supply chain

The Hacker News รายงานในสรุปรายสัปดาห์ว่า framework ของ Miasma ถูกเผยแพร่ผ่าน GitHub ช่วงสั้น ๆ และมีความสามารถกว้างกว่า worm ทั่วไป โดยรองรับการโจมตีผ่าน credential ที่ขโมยมาใน PyPI, npm, RubyGems, JFrog Artifactory, GitHub repositories, GitHub Actions, AI coding tool configuration poisoning และ SSH lateral movement อีกทั้งมี C2 ผ่าน GitHub commit search หลายช่องทาง ทำให้ความเสี่ยงต่อ CI/CD และ registry credentials สูงขึ้น

- CVE: ไม่ระบุ
- รูปแบบการโจมตี: software supply chain attack, credential theft, GitHub Actions secret theft, SSH lateral movement
- คำแนะนำ: หมุน credential ที่ใช้กับ npm/PyPI/GitHub/JFrog, ตรวจ GitHub Actions runner และ CI logs, บังคับใช้ least privilege สำหรับ token, เปิด secret scanning และตรวจ dependency/package ที่เพิ่งเพิ่มหรือเปลี่ยน maintainer
- แหล่งข่าว: https://thehackernews.com/2026/06/threatsday-bulletin-worm-code-leaked-ai.html

## Medium

### 🟡 GitHub จะปิด npm install scripts โดยค่าเริ่มต้นใน npm 12

GitHub ประกาศการเปลี่ยนแปลงใน npm 12 เพื่อปิดการรัน preinstall/install/postinstall scripts จาก dependencies โดยค่าเริ่มต้น ลดพื้นผิวโจมตีที่แพ็กเกจ npm ที่ถูกยึดหรือแทรกโค้ดสามารถรันคำสั่งบนเครื่องนักพัฒนาหรือ CI runner ได้ทันทีระหว่าง `npm install` การเปลี่ยนแปลงนี้กระทบโปรเจกต์ Node.js ที่พึ่งพา lifecycle scripts หรือ native builds เช่น node-gyp

- CVE: ไม่ระบุ
- รูปแบบการโจมตี: dependency install-time code execution, npm supply chain abuse
- คำแนะนำ: อัปเกรดเป็น npm 11.16.0 ขึ้นไปเพื่อทดลอง warning, รัน `npm approve-scripts --allow-scripts-pending`, อนุมัติเฉพาะแพ็กเกจที่ไว้ใจได้ และ commit policy ที่ได้ก่อนย้ายไป npm 12
- แหล่งข่าว: https://thehackernews.com/2026/06/github-to-disable-npm-install-scripts.html

### 🟡 Microsoft แก้ปัญหา BitLocker recovery บน Windows Server 2025

Microsoft แก้ known issue ที่ทำให้ Windows Server 2025 บางเครื่องบูตเข้า BitLocker recovery หลังติดตั้งอัปเดตความปลอดภัยเดือนเมษายน 2026 โดยเกิดกับระบบองค์กรที่มี BitLocker, TPM validation policy และเงื่อนไข Secure Boot บางแบบ แม้ไม่ใช่ช่องโหว่โจมตีโดยตรง แต่เป็นความเสี่ยงด้าน availability และการกู้คืนระบบหลังแพตช์สำหรับ Windows Server

- CVE: ไม่ระบุ
- รูปแบบการโจมตี: ไม่มีหลักฐานการโจมตี เป็น patching/availability issue
- คำแนะนำ: ติดตั้ง KB5094125 สำหรับ Windows Server 2025 หรือ KB5093998 สำหรับ Windows 11 23H2 ตามสภาพแวดล้อม, ตรวจ Event ID 1032, ทบทวน Group Policy ที่ผูก PCR7 และเตรียม BitLocker recovery key สำหรับเครื่องที่ยังไม่อัปเดต
- แหล่งข่าว: https://www.bleepingcomputer.com/news/microsoft/microsoft-fixes-bitlocker-recovery-bug-on-windows-server-2025/
