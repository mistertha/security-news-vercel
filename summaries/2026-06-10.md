### ⚠️ Microsoft ออก Patch Tuesday เดือนมิถุนายน แก้เกือบ 200 ช่องโหว่ รวม IIS, BitLocker, Windows CTFMON และ VS Code

- แหล่งข่าว: [Krebs on Security](https://krebsonsecurity.com/2026/06/a-record-breaking-patch-tuesday-for-june-2026/)
- สรุป: Microsoft ออกแพตช์รายเดือนมิถุนายน 2026 สำหรับช่องโหว่เกือบ 200 รายการใน Windows และซอฟต์แวร์ที่เกี่ยวข้อง โดยมีช่องโหว่ระดับ Critical เกือบสามโหล และมี exploit code สาธารณะอย่างน้อย 3 รายการ ข่าวระบุ zero-day ที่เกี่ยวข้องกับ IIS/เว็บเซิร์ฟเวอร์, Windows Collaborative Translation Framework, BitLocker และยังกล่าวถึงช่องโหว่ Visual Studio Code ที่อาจขโมย GitHub token ได้จากการคลิกครั้งเดียว แม้ไม่ได้ระบุว่าช่องโหว่ชุดนี้ถูกโจมตีจริงทั้งหมด แต่จำนวนช่องโหว่และ exploit ที่เผยแพร่ทำให้ต้องเร่งจัดลำดับแพตช์
- CVE: CVE-2026-49160, CVE-2026-45586, CVE-2026-50507 และช่องโหว่ VS Code ที่ข่าวกล่าวถึงแต่ไม่ได้ระบุ CVE ในข้อความ RSS/listing ที่ใช้
- รูปแบบการโจมตี: patch window exploitation, privilege escalation, denial of service, token theft, exploit-publication risk
- การดำเนินการที่แนะนำ: เร่งทดสอบและติดตั้ง Microsoft June 2026 Patch Tuesday บน Windows/Windows Server, IIS, BitLocker และ developer workstation ที่ใช้ VS Code; สำรองข้อมูลก่อนแพตช์; ตรวจสอบระบบที่เปิด IIS หรือมี developer token สำคัญ และติดตาม exploit ใหม่ที่อาจถูกปล่อยก่อนรอบแพตช์ถัดไป

### ⚠️ Chrome V8 zero-day CVE-2026-11645 ถูกใช้โจมตีจริง ต้องอัปเดต Windows และ Linux ทันที

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/google-patches-fifth-chrome-zero-day-bug-exploited-in-attacks-this-year/)
- สรุป: Google ออกอัปเดตฉุกเฉินให้ Chrome เพื่อแก้ CVE-2026-11645 ซึ่งเป็นช่องโหว่ high-severity ใน V8 JavaScript engine และ Google ยืนยันว่ามี exploit ถูกใช้ใน wild แล้ว รายละเอียดเชิงเทคนิคยังจำกัดตามแนวปฏิบัติของ vendor แต่ข่าวระบุว่าเป็น out-of-bounds read/write ที่ผู้โจมตีระยะไกลอาจกระตุ้นผ่าน HTML ที่สร้างมาเป็นพิเศษเพื่อรันโค้ดภายใน browser sandbox ช่องโหว่นี้กระทบผู้ใช้ Windows และ Linux ผ่าน Chrome desktop
- CVE: CVE-2026-11645
- รูปแบบการโจมตี: browser zero-day exploitation, malicious HTML, memory corruption, potential sandboxed code execution
- การดำเนินการที่แนะนำ: บังคับอัปเดต Chrome เป็น 149.0.7827.102 บน Windows/Linux หรือใหม่กว่า, restart browser ให้แพตช์มีผล, ตรวจสอบ Chromium-based browsers อื่นให้รับแพตช์เมื่อ vendor ปล่อย และเพิ่ม monitoring สำหรับการเปิดลิงก์/ไฟล์ HTML ที่ผิดปกติในกลุ่มผู้ใช้เสี่ยงสูง

### ⚠️ Linux kernel nf_tables CVE-2026-23111 มี public exploit ใช้ยกระดับสิทธิ์เป็น root และ escape container

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/one-character-linux-kernel-flaw-enables.html)
- สรุป: นักวิจัยเผยแพร่รายละเอียดและ exploit สำหรับช่องโหว่ use-after-free ใน nf_tables ของ Linux kernel ที่ทำให้ผู้ใช้ local privilege ต่ำสามารถยกระดับเป็น root และหลุดออกจาก container namespace ได้ เงื่อนไขโจมตีที่พบบ่อยคือระบบเปิดใช้ nf_tables และ unprivileged user namespaces ซึ่งพบได้ใน desktop และ server หลายแบบ ข่าวระบุการสาธิตบน Debian Bookworm/Trixie, Ubuntu 22.04/24.04 และการทำซ้ำบน RHEL 10 โดยไม่ใช่ remote vector โดยตรง แต่เป็นเครื่องมือสำคัญหลังผู้โจมตีได้ foothold
- CVE: CVE-2026-23111
- รูปแบบการโจมตี: local privilege escalation, Linux kernel use-after-free, container escape, post-compromise root escalation
- การดำเนินการที่แนะนำ: อัปเดต kernel ตาม advisory ของ distro แล้ว reboot, จัดลำดับระบบที่รัน container หรือรับ workload จากผู้ใช้ไม่เชื่อถือก่อน, ปิดหรือจำกัด unprivileged user namespaces หากยังแพตช์ไม่ได้ และตรวจสอบ container host สำหรับสัญญาณการยกระดับสิทธิ์ผิดปกติ

### ⚠️ Microsoft ปิดชั่วคราว 73 GitHub repositories หลังพบความเสี่ยง Miasma/Shai-Hulud supply-chain

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/github-disables-microsoft-repos-pushing-password-stealing-malware/)
- สรุป: Microsoft ลบ/ปิดชั่วคราว repositories 73 รายการในองค์กร Azure, microsoft, Azure-Samples และ MicrosoftDocs บน GitHub หลังมีความกังวลว่าเผยแพร่เนื้อหาที่อาจเป็นมัลแวร์ เหตุการณ์เกิดวันที่ 5 มิถุนายนและถูก containment ภายใน 105 วินาที หลายฝ่ายเชื่อมโยงกับแคมเปญ Miasma/Shai-Hulud supply-chain โดยกระทบ workflow ที่อ้างอิง GitHub Action เช่น `Azure/functions-action` และมีบริบทต่อเนื่องจากแพ็กเกจ PyPI `durabletask` ที่เคยถูก compromise ในเดือนพฤษภาคม
- CVE: ไม่พบในข่าว
- รูปแบบการโจมตี: software supply-chain compromise, CI/CD disruption, credential-stealing malware, GitHub Actions dependency risk
- การดำเนินการที่แนะนำ: ตรวจสอบ workflow ที่เรียกใช้ GitHub Actions จาก Microsoft/Azure repos ในช่วงเหตุการณ์, pin action เป็น commit SHA แทน branch/tag เมื่อเป็นไปได้, ตรวจ log ของ CI/CD สำหรับการดึง action หรือ package ผิดปกติ, rotate secrets ของ pipeline ที่อาจสัมผัส dependency ที่ถูก compromise และติดตามประกาศจาก Microsoft/GitHub สำหรับรายการ repo/package ที่ได้รับผลกระทบ

### ⚠️ Veeam Backup & Replication CVE-2026-44963 เปิดทาง RCE บน backup server ที่ join Windows domain

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-veeam-vulnerability-exposes-backup-servers-to-rce-attacks/)
- สรุป: Veeam ออกแพตช์แก้ CVE-2026-44963 ใน Veeam Backup & Replication 12.3.2.4465 และ build 12.x ก่อนหน้า ซึ่งเปิดทางให้ domain user สิทธิต่ำโจมตีแบบ remote code execution บน backup server ที่ join domain ได้ ข่าวระบุว่าไม่กระทบ version 13.x และยังไม่มีรายงาน active exploitation แต่ Veeam เตือนว่าหลังแพตช์เผยแพร่ ผู้โจมตีมัก reverse-engineer เพื่อสร้าง exploit อย่างรวดเร็ว Backup server เป็นเป้าหมายสำคัญของ ransomware เพราะใช้ขโมยข้อมูลและทำลายความสามารถกู้คืน
- CVE: CVE-2026-44963
- รูปแบบการโจมตี: authenticated RCE, Windows domain abuse, backup infrastructure compromise, ransomware enablement
- การดำเนินการที่แนะนำ: อัปเดต Veeam Backup & Replication เป็น 12.3.2.4854 หรือ 13.x, ตรวจว่ามี backup server ใด join domain โดยไม่จำเป็นหรือไม่, จำกัดสิทธิ domain user ต่อระบบ backup, monitor การรัน process/command แปลกปลอมบน Veeam server และตรวจสอบ backup integrity หลังอัปเดต

### ⚠️ SAP แก้ช่องโหว่ Critical ใน NetWeaver, AS Java และ Commerce Cloud รวม SAML auth bypass และ memory corruption

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/sap-fixes-critical-flaws-in-netweaver-and-commerce-cloud/)
- สรุป: SAP ออกแพตช์ June 2026 Security Patch package แก้ 15 ช่องโหว่ รวม 4 รายการระดับ Critical ใน SAP NetWeaver และ SAP Commerce Cloud ช่องโหว่สำคัญรวม XML Signature Wrapping ที่อาจนำไปสู่ SAML authentication bypass, memory corruption ใน NetWeaver/ABAP Platform, ช่องโหว่ Spring Security-related ใน Commerce Cloud/Data Hub และ directory traversal ใน NetWeaver Application Server Java Web Container ข่าวยังระบุช่องโหว่ high-severity ที่เกี่ยวกับ Apache Tomcat ใน Commerce Cloud
- CVE: CVE-2026-44748, CVE-2026-27671, CVE-2026-22732, CVE-2026-40128, CVE-2026-29145, CVE-2026-44751
- รูปแบบการโจมตี: authentication bypass, memory corruption, directory traversal, Java web container exposure, enterprise application compromise
- การดำเนินการที่แนะนำ: เร่งใช้ SAP June 2026 patches โดยเฉพาะ NetWeaver/ABAP/AS Java และ Commerce Cloud, ทบทวน SAML trust/configuration, จำกัดการเข้าถึง endpoint ภายในที่เกี่ยวข้อง, ตรวจ log authentication และ RFC request ผิดปกติ และติดตาม SAP Security Notes สำหรับ mitigation เฉพาะเวอร์ชัน
