## Critical

### 🚨 Critical — Windows Netlogon RCE ถูกใช้โจมตีแล้ว

- สรุป: ศูนย์ไซเบอร์เบลเยียมเตือนว่า CVE-2026-41089 ใน Windows Netlogon ถูกใช้โจมตีจริงแล้ว ช่องโหว่นี้เป็น stack-based buffer overflow ที่ Microsoft แพตช์ไปใน May 2026 Patch Tuesday และอาจเปิดทางให้ผู้โจมตีที่ยังไม่มีสิทธิ์ส่ง request ไปยัง Windows Server ที่เป็น domain controller เพื่อรันโค้ดจากระยะไกลได้ แหล่งข่าวระบุว่ากระทบ Windows Server รุ่นที่ยังซัพพอร์ต รวมถึง Windows Server 2025 แต่รายละเอียด IOC ยังมีจำกัด
- CVE: CVE-2026-41089
- รูปแบบการโจมตี: unauthenticated remote code execution ผ่าน Netlogon/RPC request ต่อ domain controller
- การดำเนินการที่แนะนำ: เร่งแพตช์ domain controller ด้วย May 2026 security update หรือใหม่กว่า, จำกัด exposure ของบริการที่เกี่ยวข้องกับ Netlogon/RPC, ตรวจ log การเชื่อมต่อผิดปกติไปยัง domain controller และจัดลำดับ incident response หากยังมี DC ที่ไม่ได้แพตช์
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/critical-windows-netlogon-remote-code-execution-flaw-now-exploited-in-attacks/)

## High

### ⚠️ High — Miasma โจมตี supply chain ผ่านแพ็กเกจ npm ของ Red Hat

- สรุป: แคมเปญ Miasma ซึ่งเป็นสายพันธุ์ใหม่ที่คล้าย Mini Shai-Hulud เจาะแพ็กเกจใน namespace `@redhat-cloud-services` เพื่อขโมย secret จากเครื่องนักพัฒนาและ CI/CD เช่น GitHub Actions secrets, npm tokens, cloud credentials, Kubernetes/Vault material, SSH keys และไฟล์ `.env` รายงานระบุว่ามีการใช้ preinstall hook ใน npm และมีความสามารถด้าน persistence ในเครื่องนักพัฒนา จึงไม่ควรมองว่าการลบ `node_modules` เพียงอย่างเดียวเพียงพอ
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: software supply-chain compromise, credential theft, CI/CD token abuse และ self-propagating worm behavior
- การดำเนินการที่แนะนำ: ตรวจว่ามีการติดตั้งเวอร์ชันที่ได้รับผลกระทบหรือไม่, isolate host/runner ที่เกี่ยวข้อง, rotate secrets และ tokens ทั้งหมดที่อาจถูกอ่านได้, review GitHub/npm activity, ตรวจ persistence artifacts เช่น `~/.claude/settings.json`, `.vscode/tasks.json`, `.github/workflows/codeql.yml` และ invalidate build/release artifacts ที่สร้างระหว่างช่วงเสี่ยง
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/miasma-supply-chain-attack-compromises.html)

### ⚠️ High — แพ็กเกจ npm `codexui-android` ขโมย OpenAI Codex authentication tokens

- สรุป: พบแคมเปญ supply chain ที่ฝังโค้ดอันตรายในแพ็กเกจ npm `codexui-android` ซึ่งถูกโปรโมตเป็น remote web UI สำหรับ OpenAI Codex และมีการใช้งานจำนวนมาก โค้ดดังกล่าวอ่านไฟล์ `~/.codex/auth.json` แล้วส่ง access token, refresh token, id token และ account ID ไปยังเซิร์ฟเวอร์ที่ผู้โจมตีควบคุม ความเสี่ยงสำคัญคือ refresh token อาจให้การเข้าถึงต่อเนื่องแบบเงียบ ๆ หากผู้ใช้หรือ runner เคยล็อกอิน Codex ด้วย file-based storage
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: npm supply-chain credential theft, developer-tool token exfiltration และ token replay risk
- การดำเนินการที่แนะนำ: หยุดใช้และถอนแพ็กเกจ/แอปที่เกี่ยวข้อง, rotate หรือ revoke OpenAI/Codex tokens ของผู้ใช้และเครื่อง build ที่อาจได้รับผลกระทบ, ตรวจ outbound connection ไปยังโดเมนต้องสงสัย, ตรวจว่าไฟล์ `~/.codex/auth.json` ถูกอ่านหรือส่งออกหรือไม่ และเพิ่ม policy ไม่ให้เก็บหรือแชร์ auth file ใน repository/ticket/chat
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/openai-codex-authentication-tokens.html)

## Medium

### 🟡 Medium — Operation Dragon Weave ใช้ Windows LNK, Rust loader และ Azure Blob Storage เป็น C2

- สรุป: กลุ่มที่ถูกประเมินว่า China-aligned ใช้ spear-phishing ZIP attachments ในแคมเปญ Operation Dragon Weave เพื่อโจมตีเป้าหมายใน Czech Republic และ Taiwan หนึ่งใน chain เริ่มจาก Windows Shortcut (LNK) ปลอมเป็น PDF แล้วรัน PowerShell เพื่อแตกและรัน executable ส่วนอีก chain ใช้ binary/dropper ที่เขียนด้วย Rust จากนั้นทำ DLL side-loading และปล่อย AdaptixC2 agent โดยใช้ Microsoft Azure Blob Storage เป็น dead-drop C2
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: spear phishing, Windows LNK execution, PowerShell staging, Rust loader, DLL side-loading และ cloud storage C2
- การดำเนินการที่แนะนำ: บล็อกหรือจำกัด LNK/ZIP จากอีเมลภายนอก, เพิ่ม detection สำหรับ `RuntimeBroker_update.exe`, `UnityPlayer.dll`, PowerShell extraction patterns และ Azure Blob Storage access ที่ผิดปกติ, ใช้ application control กับเครื่อง endpoint และทบทวน telemetry ของ EDR สำหรับ DLL side-loading
- แหล่งที่มา: [The Hacker News](https://thehackernews.com/2026/06/china-aligned-groups-ramp-up-attacks.html)

### 🟡 Medium — Microsoft แก้ปัญหา Windows 11 security update KB5089549 ติดตั้งล้มเหลว

- สรุป: Microsoft ระบุว่าปัญหา KB5089549 ติดตั้งล้มเหลวพร้อม error `0x800f0922` เกิดจากพื้นที่ EFI System Partition ไม่พอ โดยเฉพาะเครื่องที่เหลือ 10 MB หรือน้อยกว่า ปัญหานี้ทำให้ security update ย้อนกลับระหว่าง reboot และอาจทำให้ endpoint บางส่วนไม่ได้รับแพตช์ตามรอบ ล่าสุด Microsoft แก้ใน KB5089573 preview cumulative update และจะรวมใน June Patch Tuesday
- CVE: ไม่พบ CVE ในแหล่งข่าว
- รูปแบบการโจมตี: ไม่ใช่การโจมตีโดยตรง แต่เป็น patch deployment failure ที่เพิ่ม exposure window ให้เครื่อง Windows
- การดำเนินการที่แนะนำ: ติดตั้ง KB5089573 หรืออัปเดตใหม่กว่าเมื่อพร้อมใช้งาน, ตรวจ compliance ของ KB5089549/KB5089573 ใน fleet, ใช้ Known Issue Rollback หรือ Group Policy mitigation สำหรับเครื่องที่ยังไม่ลง preview update และตรวจ ESP free space ในกลุ่มเครื่องที่ rollback
- แหล่งที่มา: [BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/microsoft-fixes-kb5089549-windows-security-update-install-issues/amp/)
