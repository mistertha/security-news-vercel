## High

### ⚠️ Shai-Hulud ระลอกใหม่ฝังมัลแวร์ในแพ็กเกจ PyPI 19 รายการ

- แหล่งข่าว: [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-shai-hulud-attack-trojanizes-19-science-focused-pypi-packages/)
- สรุป: แฮกเกอร์ compromise แพ็กเกจ PyPI กลุ่มเครื่องมือวิทยาศาสตร์/ชีวสารสนเทศ 19 รายการ รวม 37 malicious releases เพื่อขโมย developer secrets เมื่อ Python เริ่มทำงานผ่านไฟล์ `*-setup.pth` และ payload JavaScript `_index.js` ที่พยายามดาวน์โหลด Bun runtime จาก GitHub ข่าวระบุว่า payload มุ่งเป้า GitHub/GitHub Actions secrets, npm/PyPI/RubyGems/JFrog publishing tokens, AWS/GCP/Azure/Kubernetes/Vault credentials, SSH keys, Docker credentials และไฟล์ config สำคัญ การโจมตีสอดคล้องกับแคมเปญ Shai-Hulud และมีเป้าหมายขยายผลใน workflow พัฒนาและ CI/CD
- CVE: ไม่พบในข่าว
- รูปแบบการโจมตี: software supply-chain compromise, credential theft, malicious PyPI wheel/startup hook, CI/CD secret exfiltration
- การดำเนินการที่แนะนำ: ตรวจหาแพ็กเกจ/เวอร์ชันที่ Socket ระบุว่าได้รับผลกระทบ, ค้นหา `.pth` startup hook ที่ผิดปกติและ process chain ที่ Python เรียก Bun เพื่อรัน `_index.js`, กักกันเครื่อง developer/CI ที่ติดตั้งแพ็กเกจต้องสงสัย, rotate GitHub/npm/PyPI/cloud/Kubernetes/Docker/SSH secrets ทั้งหมดที่อาจถูกอ่านได้ และ restore environment จาก backup ที่เชื่อถือได้

### ⚠️ VerdantBamboo ใช้ BRICKSTORM เวอร์ชัน BSD และ backdoor เพิ่มเติมโจมตี Linux appliance

- แหล่งข่าว: [The Hacker News](https://thehackernews.com/2026/06/verdantbamboo-deploys-bsd-variant-of.html)
- สรุป: กลุ่มจารกรรมไซเบอร์จีน VerdantBamboo ถูกพบว่าใช้ BRICKSTORM เวอร์ชัน BSD รวมถึง PLENET/GRIMBOLT และ AGENTPSD เพื่อคงการเข้าถึงระบบ Linux appliance และอุปกรณ์ที่มักไม่มี EDR ข่าวระบุว่าผู้โจมตีเคยใช้ช่องโหว่ local privilege escalation บน Egnyte Storage Sync เพื่อฝัง BRICKSTORM และใช้ความสามารถ proxy ร่วมกับ credential ที่ถูกขโมยเพื่อเข้าถึง Microsoft 365 รวมถึงพบการ compromise pfSense firewall ของ MSP ด้วย หลักฐานชี้ว่าการฝังตัวอาจยาวนานและออกแบบ persistence เฉพาะต่ออุปกรณ์
- CVE: CVE-2026-22769 ถูกกล่าวถึงในบริบทการใช้ PLENET ก่อนหน้า; ช่องโหว่ Egnyte Storage Sync ในเหตุการณ์นี้ไม่ได้ระบุ CVE ในข่าว
- รูปแบบการโจมตี: cyber espionage, appliance persistence, backdoor deployment, credential abuse, proxying through compromised infrastructure, MSP compromise
- การดำเนินการที่แนะนำ: อัปเดต Egnyte Storage Sync เป็นเวอร์ชัน 13.13 หรือใหม่กว่า, ตรวจสอบ firewall/pfSense, NAS, Linux appliance และ MSP-managed paths สำหรับ persistence แปลกปลอม, hunt หา BRICKSTORM/PLENET/AGENTPSD IOCs จากรายงาน Volexity, rotate admin/VPN/M365 credentials ที่เกี่ยวข้อง และทบทวน Conditional Access โดยไม่พึ่งพา source IP ที่อาจถูก proxy ผ่านระบบภายใน
